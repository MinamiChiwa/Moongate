# Moongate 使用說明

[简体中文](user-guide.md) · [繁體中文](user-guide.zh-TW.md) · [返回首頁](../README.zh-TW.md)

本說明對應 Moongate 0.1.8（測試版）。這一版的變化與已知問題見[更新說明](release-notes-0.1.8.zh-TW.md)。

## 1. 準備

| 項目 | 需求 |
|---|---|
| 系統 | Windows 10 1703 或更新版本 / Windows 11，64 位元（系統內建的 .NET Framework 4.x 即可，不必另裝） |
| 遊戲 | 《瑪奇 Mobile》台服 Windows 用戶端 |
| Npcap | 抓包必需，需自行安裝：[npcap.com](https://npcap.com/#download)。安裝時保持預設選項即可 |
| 存放位置 | 你有寫入權限的一般資料夾，例如 `D:\Moongate`；不要放在 `C:\Program Files`、OneDrive 同步資料夾或網路磁碟 |
| 遊戲連接器 | 角色、交易所、背包估價、生活的採集加工製作、樂譜庫遊戲內演奏與合奏換樂器需要；包內附帶，預設關閉，啟用方法見 [4.1](#41-遊戲連接器) |

在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的最新版本下方 Assets 裡下載排在最上面的 `Moongate-v0.1.8-Windows-x64.zip`（約 175 MB，解壓縮後約 450 MB），完整解壓縮後執行 `Moongate.exe`。同一發行裡的 `.sha256` 是校驗值，一般使用者不用下載。包內附帶 .NET 執行環境、染色引擎所需的 Python 環境、Tesseract 文字辨識與遊戲命令列工具，不需另外安裝。

程式沒有程式碼簽章。第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」，點「其他資訊」再點「仍要執行」。

## 2. 啟動與主畫面

執行 `Moongate.exe` 後，背景服務會隨視窗一起啟動，第一次執行時自動建立資料；關閉視窗時背景服務一起結束。視窗開著時再次按兩下 `Moongate.exe` 只會把視窗帶到前景。

- **左側欄**：上方是抓包狀態（含目前地圖）、「遊戲連接器」膠囊與遊戲視窗卡片，下方是各功能入口：DPS檢測、合奏、樂譜庫、染色、背包、角色、交易所、生活、浮窗版面。預設視窗大小下全部入口一個畫面就能放下。
- **綁定遊戲視窗**：點遊戲視窗卡片，在跳出的清單裡選擇《瑪奇 Mobile》視窗。清單為空時先啟動遊戲再點「重新整理」。設定頁可開啟「自動選擇遊戲視窗」。
- **抓包**：綁定遊戲視窗後自動開始，預設同時在所有網路卡上抓包，並一直保持執行；合奏、DPS 檢測、背包共用這一份抓包。設定頁可以關閉自動抓包，或指定只抓一張網路卡。
- **遊戲連接器**：膠囊顯示連接器狀態，點開可以啟用或還原原設定，見 [4.1](#41-遊戲連接器)。
- **狀態提示**：讀不到的資料顯示「未讀取」「未知」或「不適用」，不會用 0 代替；暫不能用的按鈕會停用，並在旁邊寫明原因。
- **說明問號**：各頁與卡片的說明收在標題旁的問號裡，滑鼠停留、Tab 聚焦或點按即可檢視。
- **調整側欄順序**：按住側欄的模組入口上下拖曳即可改變順序。

## 4. 功能

### 4.1 遊戲連接器

遊戲連接器使用《瑪奇 Mobile》自帶的命令列工具讀取與控制遊戲，Moongate 包內附帶該工具。角色、交易所、背包估價、生活的採集加工製作、樂譜庫的遊戲內演奏與遊戲樂譜同步、合奏的換樂器與開奏需要它；沒有連線時這些入口停用並寫明原因，其他功能照常使用。

1. 正常結束遊戲。遊戲執行時不能啟用、關閉或還原原設定。
2. 點側欄抓包狀態下方的「遊戲連接器」膠囊，或開啟設定頁的「遊戲連接器」卡片，開啟「啟用」。
3. 第一次啟用會跳出確認視窗，說明會修改台服用戶端的設定檔、把命令列工具複製到台服遊戲目錄、可能帶來帳號風險以及如何還原。點「我已了解，啟用」後才會修改，之後再啟用不再詢問。
4. 從 Nexon Launcher 啟動遊戲並進入角色。膠囊顯示「已連接」後即可使用。

| 膠囊狀態 | 含義與做法 |
|---|---|
| 未啟用 | 還沒有啟用連接器 |
| 遊戲啟動中 | 遊戲剛啟動、還沒進入角色；進入角色後自動連線 |
| 已連接 | 可以使用 |
| 未連接遊戲 | 已啟用，遊戲沒有執行；從 Nexon Launcher 啟動遊戲並進入角色 |
| 已失效 | 遊戲裡的連接器設定已過期；正常結束遊戲後重新啟用，再從啟動器啟動遊戲 |
| 檢測中 | 正在檢測，稍候自動重新整理 |
| 不可用 | 卡片寫明原因，例如命令列工具檔案與已核對的版本不一致、找不到台服遊戲目錄 |

- **台服遊戲目錄**：卡片顯示目錄及其來源；找不到或不對時點「更改」，填寫含 `MabinogiMobile.exe` 的資料夾後點「套用」。
- **還原原設定**：正常結束遊戲後點「還原原設定」，連接器相關的用戶端設定回到第一次啟用之前，其他設定不變。複製到遊戲目錄的命令列工具保留在原處。
- 台服遊戲目錄裡已有一個不同版本的同名命令列工具時，啟用會被拒絕，原檔案不會被覆蓋。

### 4.2 DPS 檢測

1. 確認左上角正在抓包，然後正常戰鬥。傷害自動計入目前這場與目前分段。
2. 標題列可以「拆段」（從現在起開始新分段）或「結束本場」。「自動觀測」開關控制是否自動統計。
3. **統計範圍**：整場、目前分段或定時測量。結果不完整時會顯示原因。切換地圖，或脫離戰鬥後 3 分鐘沒有戰鬥動作，這一場就結束：之後整場仍顯示上一場（標題標「上一場」），下一次造成傷害時才開始新的一場。脫離戰鬥後 10 秒內又打起來，仍算同一個分段。
4. **選擇目標**：「全部」或某個目標；選中目標時顯示對它的傷害和你的貢獻占比。目標太多時折疊為「+N」，點開展開。
5. **傷害面板**：總傷害、DPS、攻擊特性（暴擊、強擊等比率列在 DPS 下方）、首擊、元素構成與傷害歸屬；下方依序是治療、自身效果與怪物效果、破防期間、依技能／依目標明細和戰鬥紀錄。
6. **定時測量**：點時長（預設 1:00）設定分、秒，再點「開始計時」。計時從首次傷害開始，結束後結果列在測量紀錄裡。也可以在設定裡給「開始／取消定時測量」指定快速鍵。
7. **儲存紀錄**：替目前結果命名儲存；「重設」把整場、目前分段和定時測量一起清空，已儲存的戰鬥紀錄不受影響。戰鬥紀錄每列的「明細」開啟這筆紀錄的明細視窗（主數據、治療、破防、DPS 曲線、排行與總表，可依目標篩選、可匯出），標題寫紀錄名稱與儲存時間；最多同時開啟 4 個，方便對比。舊版本儲存、只有摘要的紀錄只顯示 DPS、總傷害與時長。
8. **明細視窗**：明細表左上角「在視窗中開啟」。視窗裡的範圍、目標切換只影響視窗本身；視窗裡有治療明細表，滑鼠停在 DPS 曲線上會顯示該點的時間和數值，整場曲線按電腦時鐘標注時刻。
9. **治療浮窗**：在浮窗版面頁的元件庫加入「治療」，顯示目前範圍的 HPS、總治療量、治療次數與受到治療的有效比例。
10. **效果收藏**：在效果卡片上點星號或「收藏…」。「收藏…」可以依名稱（簡繁皆可）或編號搜尋用戶端裡的全部 buff，沒在遊戲裡出現過的也能收藏。開啟「只顯示收藏」後主頁面、明細和效果浮窗都只列收藏的效果。

### 4.3 背包

1. 開著 Moongate 抓包時登入角色（已在遊戲中的可以重新登入），遊戲下發完整背包資料後自動同步。頁面標題區寫著同步狀態與時間。
2. 頂部選擇帳號；「顯示」開關選擇要看的欄組：角色保管箱、背包、公共保管箱，以及「估價」。
3. 樞紐表每列一種道具：名稱、類別、合計、公共保管箱，以及每個角色的角色保管箱與背包。「未讀取」表示這一處還沒收到資料，0 只在確知沒有時出現。樂譜每張一列，名稱就是譜名，滑鼠停在名稱上可以看到作曲、編曲、能否複製、是否收藏與上鎖。
4. **資源**卡是貨幣的集中位置，卡片用遊戲圖示顯示各項貨幣。頂部選擇角色（預設目前登入角色），其下是金幣（免費 + 付費）、銀幣與魔族貢品，銀幣和貢品在名稱下方顯示下一次補充的倒數，時間到後標「待進圖」（遊戲在下次進圖時結算）；補充上限沒有會員時為 100／10，奇幻生活全方位會員生效時為 150／15，達到上限時寫「已滿」。上限在登入或換頻道時判定，只有單項會員時不顯示上限。再往下是帳戶資源（跟隨帳號）與角色資源（跟隨所選角色）。啟用遊戲連接器時，目前登入角色的貨幣以連接器讀數為準，其他角色和連接器讀不到時用抓包資料；滑鼠停在數值上可以看到來源。
5. **估價**：開啟「顯示」裡的「估價」（需要遊戲連接器）後，表格增加「估價（德卡）」欄，依交易所最低單價乘以持有數量計算；讀不到價格時寫原因（例如無在售、不可交易），同步狀態下方寫明取價時間與已估價項目的合計，含無法估價的項目時標「下限」。開啟後每 60 秒更新一次，只在背包頁顯示時取價；開關只在本次執行內記住。
6. 搜尋框在名稱、類別、備註與樂譜的作曲、編曲裡尋找。按兩下「備註」欄或按 F2 編輯備註，備註依帳號存放在工具資料夾裡。
7. 「匯出 CSV」匯出目前看到的欄與列；「在視窗中開啟」在獨立視窗裡查看同一張表。

### 4.4 角色

角色頁需要遊戲連接器（暱稱取自抓包）。頁面顯示時才讀取，標題列的「重新整理」立即重讀。

- **概況**：暱稱、伺服器、稱號、等級、戰鬥職業，以及戰鬥力、生活力、魅力、裝飾分數四項評分。
- **狀態**：體力、護盾、飽腹、背包重量與生效 Buff 數。
- **屬性**與**生活技能**（等級與經驗）。
- **任務**：日常與週常兩個頁籤，未完成的在前，「已完成，待領獎」單列。
- **成長指南**：未解鎖的內容寫明解鎖條件。
- **周邊**：區域、頻道、天氣、遊戲內時間、位置與住宅。

每張卡片標題處寫明來源與讀取時刻（例如「遊戲連接器 · 12:03:11」），沿用上次結果時標「舊資料」，讀不到的項目顯示「未讀取」。「編輯版面」可以調整卡片的順序與大小。

### 4.5 交易所

交易所頁需要遊戲連接器，只查價，不能買賣。

1. 選擇查價方式：名稱（可輸入多個，用空格、逗號或頓號分隔，每個至少 2 個字）、分類（分類與子分類）或收藏。
2. 結果依名稱分組，列出道具名、品階／星級／賽季（有則顯示）、是否在售與最低單價（德卡），並標註取價時間。
3. 選取一列並輸入數量，查詢明細：最低與最高掛單價、平均成交價、最多三檔掛單價與數量，以及依數量計算的購買成本；數量超過三檔合計時只給已定價部分的小計並標「下限」。
4. 遊戲要求等待時按鈕停用並倒數，時間到再點；交易所暫不可用、道具不存在或有多項符合時寫明原因，多項符合時可以點選候選再查。

### 4.6 生活

生活頁由加工設施、製作、採集、專注釣魚與總佇列幾張卡片組成，標題旁的「編輯版面」可以調整順序與大小。採集、加工、製作需要遊戲連接器；專注釣魚不需要。

1. **加工設施**：每個設施一塊，圓點依序表示已完成、加工中、已安排待執行與空槽（＋）。設施內的加工依順序逐項進行，副標題寫「目前剩餘」與「全部完成」還需的時間，滑鼠停在圓點上可以看到該項多久後完成。點已完成的圓點或「全部領取」領取該設施的全部成品（沒有已完成項目時「全部領取」停用）；點空槽在配方選單裡選擇配方與項數，加入總佇列末尾。遊戲沒有提供設施等級與槽位總數，設施塊畫出已有的加工項目與一個空槽，遊戲回報槽位已滿時寫「槽位已滿」。
2. **製作**：依製作設施分塊，點開後在配方選單裡看到成功率、大成功率、每次產出與材料持有／需要，填好次數加入總佇列。製作執行尚未經實機確認，介面上有標註。
3. **採集**：依生活技能折疊，展開後填寫目標數量（個，預設 10）加入總佇列。命令列每次以 10 個為目標採集，實得可能更多，累計達到目標數量即完成。釣魚類採集物請用專注釣魚。
4. 配方選單頂部可以依配方名或材料名搜尋。
5. **總佇列**：任務依順序執行，可以拖曳或用上移、下移排序，改數量或刪除。頁面頂部的控制列有「開始」（暫停後為「繼續」）、「暫停」（目前這一次呼叫結束後停下）、「停止目前」（立即中斷，遊戲裡這一次的結果視為未知）與「清空已完成」。
6. **花費確認**：開始或繼續前會列出每項的單次花費與次數、整個佇列的花費上限，並提醒會自動移動角色；採集、加工、製作每次消耗精靈之翼，領取不消耗。確認後才執行，可以勾選「本次執行期間不再詢問」。
7. 任務遇到遊戲拒絕、遊戲裡有介面擋住、精靈之翼或材料不足時，整個佇列暫停，寫明原因、停在哪一項和已完成多少，不跳過、不自動重試；處理後點「繼續」從該項剩餘的部分接著執行。
8. 加工完成時左上角狀態會提示，不跳出視窗、不響鈴。「到點自動領取」預設關閉，開啟後只在本次執行內有效。
9. 關閉 Moongate 後佇列保留，下次開啟時處於暫停並寫明「工具重啟後暫停」，確認後手動繼續。
10. **專注釣魚**：
    - 條件：已綁定遊戲視窗，視窗沒有最小化，遊戲畫面區域為 1280×960。條件不滿足時「開始釣魚」停用並寫明原因。
    - 先把角色停在可釣魚的位置，設定時長（小時、分鐘、秒；全部留空表示直到停止，填寫時為 1 分鐘到 24 小時），點「開始釣魚」並確認。工具原地拋竿、收竿與續拋，不尋路；執行期間在背景對遊戲視窗傳送 W/S、空白鍵按鍵與點按。
    - 執行中顯示階段、已用時長與目標時長、輪次統計。「收竿結束」離開釣魚姿態後結束，「立即停止」馬上停止。背包滿時自動停止。
    - 專注釣魚與總佇列、合奏、演奏、染色不能同時進行。
11. 浮窗元件「加工設施」顯示各設施的圓點與剩餘時間，「生活佇列」顯示佇列狀態、目前任務與進度和下一項；元件解鎖後可以領取、點空槽安排加工、暫停、繼續或停止目前任務。

### 4.7 合奏

1. **連線房間**：填寫暱稱（預設用抓包辨識到的角色名，也可切換為自訂暱稱），選擇連線方式：
   - 伺服器直連：房主「建立公網房間」，成員輸入六位房間碼「加入房間」。
   - 區域網路：同一路由器或已用組網軟體互通的電腦之間使用，房主選擇本機位址，成員填寫房主位址與房間碼。頁面裡有「連線教學」。
   - Cloudflare 公網需要另外設定 cloudflared 元件，包內未附帶。
2. 房主建房後可「複製邀請」傳給成員。
3. **成員表**：房主可以編輯每位成員的組號、順序、身分（樂譜使用者／參與者）與樂器，按住列拖動調整，右鍵或列尾「···」指定總指揮或移出房間。
4. **本機動作**：開啟「操作遊戲」，設定開始方式與停止方式；需要點擊遊戲內按鈕時用「點選按鈕位置」在遊戲視窗上點一下記錄位置。
5. **開奏**：成員按「就緒」，房主按「開始」。倒數結束時工具替每組的樂譜使用者點擊樂譜「使用」或按開始鍵，參與者在遊戲裡依順序加入合奏。
6. **停止**：房主可以取消本輪或全員停止；總指揮演奏結束時可以帶動全員一起停止；成員可用「本機停止」。工具停止失敗時會提示你在遊戲中手動停止。
7. **遊戲連接器**：啟用並連線後，成員表裡分配了樂器的成員按「就緒」時，工具先在遊戲裡換成該樂器再就緒；背包裡沒有該樂器或名稱有歧義時無法就緒並寫明原因。樂譜使用者的樂譜是遊戲自帶樂譜時，開奏透過連接器送出，停止也透過連接器執行；玩家自製樂譜仍依設定的開始方式（點擊或按鍵）開奏。
8. 浮窗裡的「資訊浮窗」元件顯示房間碼、倒數、成員與就緒狀態，解鎖後可直接點「開始」「就緒」。

### 4.8 染色

1. 開啟遊戲的染色介面，綁定遊戲視窗。
2. 三張區域卡各自設定：是否啟用、優先順序、目標色（輸入 HEX、用選色浮層或滴管）、模式（精準 HEX，或相似顏色加 ΔE 容差）以及替代色（最多 63 個）。改動自動儲存。
3. **滴管**：點滴管後工具切到遊戲視窗，先擷取游標所在的螢幕並凍結畫面，游標移到其他螢幕時再擷取那一塊；在凍結畫面上左鍵取色，右鍵或 Esc 取消。各螢幕縮放比例不同時也能準確取到游標下的像素。
4. **選色方案**：把目前設定存成方案，或套用內建的「日系插畫配色」「時尚設計配色」共十套預設。
5. 按「開始」尋色。開始前需要：已綁定遊戲視窗且視窗沒有最小化，程式資料夾裡有完整的 `components\color-engine`（解壓版內附）。條件不滿足時「開始」停用，旁邊寫明缺的是哪一項。開始後工具把遊戲視窗切到前景，擷取遊戲視窗畫面辨識色盤並操作滑鼠；尋色期間請讓遊戲視窗保持在前景、不要移動或縮放視窗，切走或改變視窗會停止這次尋色。選「精準尋色」時工具還會唯讀遊戲記憶體，用戶端版本不受支援時會停止並寫明原因。
6. 執行列的狀態列顯示目前階段與步驟，下面一行說明這一步在做什麼、需要你做什麼（例如「請進入染色介面」），並列出遊戲實測色碼與色差；也顯示剩餘時間與各區域判定。截圖尋色完成一輪後顯示「本輪尋色已完成」，可點「重試」在本局剩餘時間內再找一次；有多個候選時可以選擇。按「停止」或 **F9** 立即停止。
7. 尋色沒有完成時，狀態列寫明結果（例如「遊戲失去焦點，已停止尋色」「無法讀取遊戲程序（權限被拒絕）」「等待染色介面逾時」），說明列給出原因與下一步；精準尋色準備失敗時還寫明停在哪一步。遊戲以系統管理員身分執行時，精準尋色需要以系統管理員身分執行 Moongate。
8. 區域卡的「目前」「實測」是工具在遊戲畫面上讀到的色碼：尋色進行中顯示最新一次讀到的顏色、色差與判定，沒讀出的區域顯示「未讀取」；結束時沒有再次核對遊戲顏色的，「實測」一行標為「上次實測（目前未確認）」，這時請以遊戲目前顏色為準。
9. 浮窗版面裡的「目前顏色」元件在遊戲上方顯示同樣的內容：目前階段與指引、剩餘時間、各區域實測色碼與色差、結果與下一步，有候選時可以選擇；解鎖元件後可以點「停止」或「重試」，上鎖時滑鼠穿透到遊戲。
10. 遊戲和 Moongate 可以放在不同的螢幕上，螢幕縮放為 100%、125%、150% 都可以尋色。
11. **尋色紀錄**保留最近 30 次的結果。

### 4.9 樂譜庫與迷你窗

1. **樂譜來源**：樂譜表合併三類來源，名稱前的標籤區分「遊戲樂譜」（遊戲自帶的樂譜，透過遊戲連接器從遊戲同步）、「自製樂譜」（從背包抓包讀到的玩家自製與複製樂譜，不需要連接器）和「匯入」（以前版本匯入的樂譜），表頭上方可以依來源篩選。開啟頁面、點「重新同步」以及頁面顯示期間每分鐘同步一次。遊戲裡已經沒有的樂譜標「遊戲裡已沒有」，不能加入佇列。
2. 樂譜表列出名稱、編曲、時長與操作。選取列後按 Ctrl+C 或右鍵「複製樂譜名」只複製樂譜名，每列一個。
3. **清單**：每列的「加入清單」把樂譜加入某個清單。「管理清單」裡可以新增清單與資料夾，替清單改名、寫備註、指定預設樂器、移動或刪除（刪除要再點一次「確認刪除」），調整清單裡樂譜的順序、移除或替單首指定樂器。
4. **演奏佇列**：「加入佇列」需要先綁定遊戲視窗。佇列每一項可以選擇「遊戲目前樂器」（不換樂器）或目前角色背包裡的樂器（背包同步後列出，名稱為遊戲原文）；從清單加入時帶上清單裡指定的樂器。演奏進行中不能改樂器。
5. **遊戲內演奏**：標題區的「遊戲內演奏」開啟操作層，有開始演奏、下一首、停止、目前曲目與狀態，以及播放順序、曲間等待等設定。開始前依每一項指定的樂器換樂器，再在遊戲裡演奏，並依佇列連續播放。這些操作需要遊戲連接器；玩家自製樂譜受遊戲限制不能透過連接器演奏，選取時「開始演奏」停用並說明。遊戲拒絕演奏（例如戰鬥中、騎乘中、沒有樂器）時寫明原因。
6. **迷你窗**：標題區的「迷你窗」開啟窄長的小視窗，與主視窗同時使用，可以選清單、選樂譜加入佇列，開始演奏、下一首、停止與緊急停止。
7. 樂譜庫不再提供匯入入口，以前匯入的清單與樂譜照常顯示。

### 4.10 浮窗

1. 開啟「浮窗版面」頁。元件庫裡每個元件右側的開關決定它是否顯示在浮窗上（DPS、技能、自身效果、怪物效果、收藏浮窗、覺醒監控、定時測量、治療、合奏資訊、目前演奏、目前顏色、加工設施、生活佇列等）；點元件本身只是選取，在右側調整縮放、外觀（玻璃、純色、自訂圖片）、背景與內容不透明度和配色。新開啟的元件預設解鎖，可以直接拖動。
2. **在螢幕上擺放**：按「螢幕上擺放」卡片的「編輯位置」，元件直接顯示在各螢幕上（包括已關閉的元件），拖曳擺放、拖右下角改尺寸，完成後按螢幕頂部提示列或卡片上的「完成編輯」儲存。
3. **換螢幕**：所選元件詳情裡的「移到顯示器」、卡片上的「全部移到」，或編輯時元件上的箭頭按鈕都可以把元件換到另一個螢幕；「全部移回主顯示器」與「恢復預設位置」用來找回看不見的元件。透過遠端桌面操作、無法直接跨螢幕拖曳時用這些按鈕。
4. 可以儲存多套版面，點「顯示浮窗」在遊戲上方顯示。浮窗每個螢幕一個，置頂且不搶遊戲焦點。
5. 浮窗上每個元件右上角有鎖和關閉按鈕：上鎖後滑鼠穿透到遊戲，解鎖後可以拖曳、改尺寸與操作，停留時還可以用「－／＋」調整縮放、用半圓按鈕調整不透明度。**F8** 顯示或隱藏浮窗，**F7** 全部上鎖或解鎖。
6. 「環境資訊」（頻道、區域、天氣與遊戲內時間）與「附近演奏字幕」（附近玩家正在演奏的曲目，同一曲目只提示一次）放在「需要遊戲資料的元件」裡，需要遊戲連接器；暫不可用時標註原因。
7. 可選「遊戲最小化時隱藏」與「錄影時隱藏」。
8. **配色**：「配色」卡片調整整個浮窗的顏色（底板、文字、強調與狀態、條形、效果條目、圖示），每組可恢復原配色；選取某個元件後還可以單獨設定它的底板與文字顏色。
9. **收藏浮窗**：「收藏浮窗 1」「收藏浮窗 2」只顯示你收藏的 buff，不受「只顯示收藏」影響。選取後在右側勾選每個收藏要看「自身」還是「目標」（目標與 DPS 浮窗血量條是同一個目前目標）。沒出現的 buff 變暗常駐；換地圖後自身 buff 標「推算」繼續倒數；元件解鎖時按住一項拖動排序。
10. **覺醒監控**：單獨的「覺醒監控」元件顯示第一季徽章覺醒：覺醒時亮起，顯示徽章名與剩餘時間並閃爍，結束後顯示冷卻倒數。DPS 元件內也有同樣的徽章覺醒顯示，預設開啟，可在 DPS 元件的設定裡關閉。兩處共用一組設定：閃爍顏色、時長與提示音（預設關閉，可用內建音或本機 wav／mp3），在任一處修改另一處同步。

### 4.11 模組與擴充

- **已安裝模組**：查看各模組狀態，啟用或停用非核心模組。
- **素材包**：「匯入素材包」選擇一個含 `pack.json` 的資料夾，替換圖示、背景與動效；移除即恢復內建外觀。製作方法見[素材包製作](asset-packs.md)（簡體中文）。
- **擴充模組**：「安裝擴充模組」選擇 `.zip`，先顯示檢查結果（識別碼、版本、發布者、檔案數、大小、簽章狀態），確認後安裝。帶程式的擴充還會列出執行方式、申請的一般權限與高風險權限、存取的主機。安裝的擴充預設停用，可隨時啟用、停用或解除安裝。也可以把 `.zip` 放進擴充資料夾的 `inbox` 裡，在頁面上逐個檢查安裝。
- **權限**：一般權限（讀取資料、提供頁面與浮窗元件等）在確認安裝時授予；截圖、連網、讀取檔案、操作遊戲等高風險權限預設關閉，在擴充卡片上逐項按「授予」開啟，隨時可以「撤銷」，撤銷立即生效。
- **執行狀態與日誌**：帶程式的擴充在獨立程序裡執行，卡片顯示執行狀態；出錯時可以按「重新啟動」，按「日誌」檢視最近的輸出。擴充提供的頁面在側欄「擴充」分組裡，浮窗元件在浮窗版面頁的元件庫裡，設定項在設定頁「擴充」卡片裡。
- 擴充程式以目前 Windows 使用者身分執行，請只安裝信任來源的擴充。製作方法見[擴充模組開發](extensions.md)（簡體中文）。

### 4.12 診斷

- **執行狀態**：背景各部分的狀態，可「複製全部」。
- **最近紀錄**：依模組與層級篩選。
- **除錯採集**：限時記錄更詳細的執行資訊，開始前會說明收集範圍。
- **匯出排查包**：把診斷資訊打包儲存，用於回報問題。

## 6. 資料位置、升級與解除安裝

所有檔案都在工具資料夾內：

| 位置 | 內容 |
|---|---|
| `Moongate.exe` | 啟動入口 |
| `components` | 程式本體與隨包執行環境 |
| `licenses` | 第三方聲明（`THIRD_PARTY_NOTICES.txt`，含本專案 MIT 授權）與元件清單 `sbom.spdx.json` |
| `userdata\data` | 資料庫、設定、記錄檔、診斷、備份、擴充模組（第一次執行後出現，下同） |
| `userdata\desktop` | 介面偏好、浮窗版面、背包備註、效果收藏、素材包 |
| `userdata\bootstrap`、`userdata\runtime` | 啟動設定與執行中的實例資訊 |

**程式內更新。** 設定頁「更新」卡片顯示目前版本、發現的新版本、本次是「增量更新」還是「完整下載」及下載大小、下載進度、上次檢查時間和上次安裝結果。開啟自動檢查時，每次開啟 Moongate 約 10 秒後檢查一次，之後按設定的間隔檢查；還沒檢查過時狀態寫「尚未檢查」，發現新版本時視窗右上角出現「有新版本」提示。增量更新只從完整包裡取本機缺少或有變化的檔案，隔了幾個版本也一樣；要換的檔案接近整個程式或網路不支援分段下載時自動改為下載完整包，顯示實際大小；增量失敗時同時說明原因，重新檢查或重用下載內容後也保留；沒有新版本時狀態寫「已是最新版本」，連不上 GitHub 時寫明原因。發現新版本後點「下載更新」，會先彈出確認視窗，顯示新版本、下載方式與大小和這個版本的更新說明（只顯示目前介面語言的那一份），點「下載」才開始下載，點「取消」、視窗外或按 Esc 都不下載；下載並校驗完成後點「安裝並重新啟動」：正在演奏、染色、定時測量或在房間裡時會先等這些活動結束；隨後 Moongate 關閉，替換程式檔案後自動開啟新版本。新版本沒能正常啟動時會自動回到原來的版本並復原資料，設定頁寫明原因。工具只從本專案的 GitHub Releases 下載（不依賴 GitHub API，連不上時才改用），核對 SHA-256 與每個檔案的內容後才安裝，不會降級。

**從 0.1.6 或更早版本升級到本版。** 請按下面的手動升級步驟操作；0.1.7 可以直接在應用程式內更新。

**手動升級。** 把新版本的壓縮檔解壓縮到一個新資料夾，關閉 Moongate，把舊資料夾裡的 `userdata` 整個移到新資料夾裡（與新的 `Moongate.exe` 放在一起），再執行新的 `Moongate.exe`；確認正常後刪除舊資料夾。也可以在關閉 Moongate 後，用新包裡的 `components`、`licenses` 與 `Moongate.exe` 取代舊資料夾裡的同名三項。自動更新失敗且舊版本也無法開啟時，工具會彈出同樣的步驟。

解除安裝時先關閉 Moongate 視窗，再刪除整個資料夾即可。

## 7. 常見問題

**抓包狀態寫「未安裝 Npcap」。** 安裝 Npcap 後不需重新啟動，工具每隔 5–60 秒自動重試，約一分鐘內開始抓包；也可以在設定裡把自動抓包關閉再開啟立即重試。

**裝了 Npcap 仍然抓不到資料。** 網卡選「自動」時，工具同時在所有網卡上抓包（包括加速器的隧道網卡和 Npcap 的迴環介面卡），只收遊戲程式自己的連線，並按遊戲資料的特徵認出真正的遊戲連線，不需要選網卡；狀態裡的「來源」寫明資料來自哪類網卡，例如「迴環（加速器）」。抓包中約 20 秒仍顯示「收不到遊戲資料」時：先確認安裝 Npcap 時勾選了「Support loopback traffic」（迴環支援，預設勾選；沒勾選時重新執行安裝程式勾上），多數本機代理型加速器的遊戲資料只在迴環上；仍不行時到設定頁的抓包部分點「列出網卡」，或用「開始檢測」找出有遊戲資料的網卡後確認使用該網卡。顯示「等待角色資訊，請切換一次地圖」時，在遊戲裡切換一次地圖或頻道即可。

**載入地圖或地下城重試時 DPS 中斷。** 遊戲載入期間視窗短暫沒有回應或重建視窗時，工具保持對同一遊戲的綁定和抓包，載入結束後 DPS 繼續統計；載入期間合奏、染色等需要操作遊戲視窗的功能暫停，視窗恢復後可繼續。抓包因故重新開始時，工具沿用先前辨識的本機角色；如果顯示「等待角色資訊，請切換一次地圖」或「角色待確認，請切換一次地圖」（沿用的角色在新地圖裡沒有得到確認，這時 DPS 不統計，避免算錯），切換一次地圖即可。野外人多、遊戲連線頻繁變化時偶爾漏掉一小段資料，DPS 分段照常繼續，只標為資料不完整。

**狀態寫「指定的網卡不存在，已改為自動」。** 設定裡指定的網卡已拔除、改名或換了電腦，工具改為在所有網卡上抓包，抓包照常進行；到設定頁重新指定網卡或改回「自動」後，這句提示消失。

**遊戲更新後。** 工具會讀取本機的新版遊戲檔案自動核對，核對期間顯示「正在核對新版遊戲」，通過後照常抓包，狀態寫「已適配新版遊戲」。新版只調整了資料編號、結構沒變時，工具依名稱自動對應，功能照常。某項功能的資料格式在新版裡有變化時，只停用這一項並寫明（例如「新版遊戲：戰鬥統計暫停用」），其他功能照常；等工具更新後恢復。

**合奏頁沒辨識出我的角色。** 確認正在抓包後，在遊戲裡切換一次地圖。

**背包一直顯示「未讀取」。** 背包資料在角色登入時下發。開著 Moongate 抓包時重新登入角色。

**遊戲連接器顯示「未連接遊戲」「遊戲啟動中」或「已失效」。** 啟用後需要從 Nexon Launcher 重新啟動遊戲並進入角色；遊戲剛啟動、還沒進入角色時顯示「遊戲啟動中」，進入角色後自動連線。顯示「已失效」時，正常結束遊戲，在膠囊裡重新啟用，再從啟動器啟動遊戲。

**啟用遊戲連接器時提示遊戲正在執行。** 啟用、關閉與還原原設定都要先正常結束遊戲。

**角色頁、交易所或生活頁的按鈕是灰的。** 這些功能需要遊戲連接器，按鈕旁寫明原因（例如「遊戲連接器未啟用」），依 [4.1](#41-遊戲連接器) 啟用並連線後自動恢復可用。

**樂譜的「開始演奏」是灰的。** 選取的是玩家自製樂譜時，遊戲不允許透過連接器演奏；遊戲連接器沒有連線時，「遊戲內演奏」層頂部寫明原因。

**生活佇列暫停了。** 頁面頂部的橫幅寫明原因、停在哪一項和已完成多少。依提示在遊戲裡處理（例如關閉擋住的介面、補充精靈之翼或材料）後點「繼續」；工具重啟後的暫停確認後直接繼續。

**專注釣魚不能開始。** 看「開始釣魚」旁寫的原因：需要先綁定遊戲視窗，視窗不能最小化，遊戲畫面區域需要正好 1280×960；總佇列、合奏、演奏或染色進行中時也不能開始。

**啟動時提示無法寫入。** 工具資料夾沒有寫入權限。把整個資料夾移到 `D:\Moongate` 這類一般位置。

**按兩下後沒有視窗，或提示背景服務啟動失敗。** 背景服務沒能啟動時，底部「未連接後端」處會寫明原因和做法：程式放在 Program Files 等受保護目錄、桌面或文件被 Windows「受控資料夾存取」攔截、網路位置、同步碟目錄、防寫的隨身碟，或資料屬於其他 Windows 使用者。依提示把整個 Moongate 資料夾移到 `D:\Moongate` 之類的一般資料夾，或在「Windows 安全性 → 病毒與威脅防護 → 勒索軟體防護 → 允許應用程式通過受控資料夾存取」中加入 `components\dotnet-runtime\dotnet.exe` 與 `components\desktop\MabiTool.Desktop.exe`。需要回報時到診斷頁按「匯出啟動記錄」儲存一個文字檔（使用者名稱已替換）給開發者。在壓縮檔檢視器裡直接執行時，工具會提示先完整解壓縮。第一次啟動若中途失敗或被打斷（例如被防毒軟體結束、斷電），舊版本之後會一直提示「初始化須使用空目錄」；新版本會接著完成初始化，升級後直接開啟即可，不需要刪除 `userdata`。只有 `userdata\data` 裡放進了不屬於 Moongate 的檔案時才會拒絕，並寫明是哪一個檔案。

**底部顯示「未連接後端」。** 底部狀態與設定頁「後端」卡片的「連接」一行寫有原因。寫著「本機連接埠 19998 已被佔用」時，是另一個資料夾裡的 Moongate 仍在執行（解壓縮了兩份，或舊的一份沒結束就開啟了新的一份）：關閉那一份的 Moongate 視窗，或在工作管理員的「詳細資料」裡結束命令列含 MabiTool.Host 的 dotnet.exe，然後重新開啟。19998 被其他軟體佔用或被系統保留時 Moongate 會自動改用空閒連接埠，不需要處理，設定頁「後端」卡片的「位址」一行顯示實際連接埠。其他原因依提示處理；需要回報時在診斷頁匯出啟動記錄。

**怎樣完全結束。** 關閉 Moongate 視窗即可：背景服務隨視窗一起結束，正在進行的合奏演奏、染色與定時測量會停止並釋放遊戲操作，生活佇列保留到下次開啟時處於暫停，不留背景程序。視窗開著時再次按兩下 `Moongate.exe` 只會把視窗帶到前景。背景服務意外停止時底部狀態寫「後端已停止」，Moongate 會自動重新啟動它一次；再次停止時請關閉並重新開啟 Moongate。

**工具點不動遊戲，或綁定時提示「遊戲以系統管理員身分執行」。** 遊戲以系統管理員身分執行時，Windows 不允許一般權限的程式操作它，Moongate 不會綁定這樣的視窗。關閉 Moongate 後在 `Moongate.exe` 上按右鍵選「以系統管理員身分執行」，或改以一般身分啟動遊戲。

**合奏用區域網路建房，別人連不上。** 第一次建房時 Windows 防火牆會詢問是否允許 `dotnet.exe`（Moongate 的背景服務）存取網路，請勾選「私人網路」並允許。加入方提示「連不上房主，請檢查防火牆」時，請房主在「Windows 安全性 → 防火牆與網路保護 → 允許應用程式通過防火牆」裡為 `dotnet.exe` 勾選「私人」，並在「設定 → 網路和網際網路」裡把目前的網路設為「私人網路」（「公用網路」下區域網路連線會被攔截）。邀請裡列出多個位址時，優先用與對方同一網段的那個。

**螢幕較小或開了 125%／150% 縮放。** 主視窗啟動時會依螢幕可用區域自動縮小，標題列始終在螢幕內；頁面內容可以上下捲動。

**遊戲裝在其他磁碟並用連結掛回原路徑。** 可以正常使用，工具會依實際位置核對遊戲檔案。

**電腦開了系統代理或加速器的代理模式。** 不影響 Moongate 視窗與背景服務之間的連線；檢查更新存取 GitHub 時沿用系統代理。

**系統版本過舊。** 低於 Windows 10 1703 時雙擊 `Moongate.exe` 會提示升級系統。

**精準尋色沒有開始操作就停止了。** 按執行列的提示處理：
- 「色卡被其他視窗遮擋」：把擋在染色畫面上的視窗（聊天、錄影、通知等）移開後重新開始。尋色期間蓋在遊戲畫面上的 Moongate 視窗（主視窗、浮窗、明細窗）會自動不進入截圖（Windows 10 2004 及更新），不用手動隱藏；這些視窗這時也不會出現在錄影和遠端桌面畫面裡，把它移開遊戲畫面即可恢復顯示。沒有蓋住遊戲的視窗照常顯示。
- 「色碼辨識逾時」：電腦較忙時文字辨識來不及完成。關閉佔用大的程式後重試，也可以改用截圖尋色。
- 「色碼核對不一致」「色塊顏色有偏差」：關閉顯示卡或螢幕的畫面濾鏡、夜間模式、HDR 與色彩增強後重試。
- 「畫面解析度無法對應」：遊戲用了低於螢幕的全螢幕解析度或解析度縮放。請改為視窗化，或把遊戲解析度設為與顯示器一致。
- 「顯示縮放導致畫面尺寸不一致」：還原遊戲視窗後重新開始；仍出現時把 Moongate 與遊戲放在同一個顯示器上。
- 「遊戲引擎已更新」：這一版 Moongate 還不認得新的遊戲引擎，精準尋色暫不可用，請改用截圖尋色，等待工具更新。
- 「文字辨識讀不到路徑」：Moongate 資料夾的路徑裡有系統編碼不支援的字，把整個資料夾移到 `D:\Moongate` 這類純英文路徑。
- 「缺少 Windows 媒體功能套件」：Windows N／KN 版本需要先在「設定 → 應用程式 → 選用功能 → 新增功能」中安裝「媒體功能套件」，重新開機後再開啟 Moongate。

**浮窗擋住了遊戲操作。** 按 F7 把全部元件上鎖，滑鼠即可穿透到遊戲；或按 F8 隱藏浮窗。

**想回報問題。** 在「診斷」頁匯出排查包，連同重現步驟提交到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。
