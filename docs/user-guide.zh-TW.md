# Moongate 使用說明

[简体中文](user-guide.md) · [繁體中文](user-guide.zh-TW.md) · [返回首頁](../README.zh-TW.md)

本說明對應 Moongate 0.1.1（測試版）。這一版的功能清單與已知問題見[更新說明](release-notes-0.1.1.zh-TW.md)。

## 1. 準備

| 項目 | 需求 |
|---|---|
| 系統 | Windows 10 / 11 64 位元 |
| 遊戲 | 《瑪奇 Mobile》台服 Windows 用戶端 |
| Npcap | 抓包必需，需自行安裝：[npcap.com](https://npcap.com/#download)。安裝時保持預設選項即可 |
| 存放位置 | 你有寫入權限的一般資料夾，例如 `D:\Moongate`；不要放在 `C:\Program Files`、OneDrive 同步資料夾或網路磁碟 |

在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的最新版本下方 Assets 裡下載排在最上面的 `Moongate-v0.1.1-Windows-x64.zip`（約 170 MB，解壓縮後約 430 MB），完整解壓縮後執行 `Moongate.exe`。同一發行裡的 `.sha256` 是校驗值，一般使用者不用下載。包內附帶 .NET 執行環境、染色引擎所需的 Python 環境與 Tesseract 文字辨識，不需另外安裝。

程式沒有程式碼簽章。第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」，點「其他資訊」再點「仍要執行」。

## 2. 啟動與主畫面

執行 `Moongate.exe` 後，背景服務會隨視窗一起啟動，第一次執行時自動建立資料；關閉視窗時背景服務一起結束。視窗開著時再次按兩下 `Moongate.exe` 只會把視窗帶到前景。

- **左側欄**：上方是遊戲視窗卡片與抓包狀態（含目前地圖），下方是各功能入口。核心功能尚未完成的模組收在「未實作模組」分組裡。
- **綁定遊戲視窗**：點遊戲視窗卡片，在跳出的清單裡選擇《瑪奇 Mobile》視窗。清單為空時先啟動遊戲再點「重新整理」。設定頁可開啟「自動選擇遊戲視窗」。
- **抓包**：綁定遊戲視窗並確定網路卡後自動開始，並一直保持執行；合奏、DPS 檢測、背包共用這一份抓包。設定頁可以關閉自動抓包、查看或更換網路卡。
- **狀態提示**：讀不到的資料顯示「未讀取」「未知」或「不適用」，不會用 0 代替；暫不能用的按鈕會停用，並在旁邊寫明原因。
- **說明問號**：各頁與卡片的說明收在標題旁的問號裡，滑鼠停留、Tab 聚焦或點按即可檢視。
- **調整側欄順序**：按住側欄的模組入口上下拖曳即可改變順序。

## 3. 設定

| 設定項 | 說明 |
|---|---|
| 語言 | 简体中文 / 繁體中文 |
| 主題與動效 | 淺色 / 深色，動效可關閉 |
| 抓包 | 自動抓包開關、網路卡清單與偵測；缺少 Npcap 時有「查看指引」 |
| 快速鍵 | 全域快速鍵的查看與修改，見第 5 節 |
| 更新 | 自動檢查開關、檢查間隔與下載限速；檢查、下載與「安裝並重新啟動」，以及上次安裝的結果，見第 6 節 |
| 後端 | 連接狀態與原因、位址（預設連接埠 19998 被其他軟體佔用時顯示自動改用的連接埠）、版本 |
| 關於 | 版本與後端資訊 |

## 4. 功能

### 4.1 DPS 檢測

1. 確認左上角正在抓包，然後正常戰鬥。傷害自動計入目前這場與目前分段。
2. 標題列可以「拆段」（從現在起開始新分段）或「結束本場」。「自動觀測」開關控制是否自動統計。
3. **統計範圍**：整場、目前分段或定時測量。結果不完整時會顯示原因。切換地圖，或脫離戰鬥後 3 分鐘沒有戰鬥動作，這一場就結束：之後整場仍顯示上一場（標題標「上一場」），下一次造成傷害時才開始新的一場。脫離戰鬥後 10 秒內又打起來，仍算同一個分段。
4. **選擇目標**：「全部」或某個目標；選中目標時顯示對它的傷害和你的貢獻占比。目標太多時折疊為「+N」，點開展開。
5. **傷害面板**：總傷害、DPS、攻擊特性（暴擊、強擊等比率列在 DPS 下方）、首擊、元素構成與傷害歸屬；下方依序是治療、自身效果與怪物效果、破防期間、依技能／依目標明細和戰鬥紀錄。
6. **定時測量**：點時長（預設 1:00）設定分、秒，再點「開始計時」。計時從首次傷害開始，結束後結果列在測量紀錄裡。也可以在設定裡給「開始／取消定時測量」指定快速鍵。
7. **儲存紀錄**：替目前結果命名儲存；「重設」把整場、目前分段和定時測量一起清空，已儲存的戰鬥紀錄不受影響。
8. **明細視窗**：明細表左上角「在視窗中開啟」。視窗裡的範圍、目標切換只影響視窗本身；視窗裡有治療明細表，滑鼠停在 DPS 曲線上會顯示該點的時間和數值，整場曲線按電腦時鐘標注時刻。
9. **治療浮窗**：在浮窗版面頁的元件庫加入「治療」，顯示目前範圍的 HPS、總治療量、治療次數與受到治療的有效比例。
10. **效果收藏**：在效果卡片上點星號或「收藏…」，開啟「只顯示收藏」後主頁面和浮窗都只列收藏的效果。

### 4.2 背包

1. 開著 Moongate 抓包時登入角色（已在遊戲中的可以重新登入），遊戲下發完整背包資料後自動同步。頁面標題區寫著同步狀態與時間。
2. 頂部選擇帳號；「顯示」開關選擇要看的欄組：角色保管箱、背包、公共保管箱。
3. 樞紐表每列一種道具：名稱、類別、合計、公共保管箱，以及每個角色的角色保管箱與背包。「未讀取」表示這一處還沒收到資料，0 只在確知沒有時出現。樂譜每張一列，名稱就是譜名，滑鼠停在名稱上可以看到作曲、編曲、能否複製、是否收藏與上鎖。
4. **概況**卡片顯示角色、道具種數、金幣（免費 + 付費）、銀幣與魔族貢品，銀幣和貢品顯示下一次補充的倒數。**資源**區分帳號資源（跟隨帳號）與角色資源（可切換角色）。
5. 搜尋框在名稱、類別、備註與樂譜的作曲、編曲裡尋找。按兩下「備註」欄或按 F2 編輯備註，備註依帳號存放在工具資料夾裡。
6. 「匯出 CSV」匯出目前看到的欄與列；「在視窗中開啟」在獨立視窗裡查看同一張表。

### 4.3 合奏

1. **連線房間**：填寫暱稱（預設用抓包辨識到的角色名，也可切換為自訂暱稱），選擇連線方式：
   - 伺服器直連：房主「建立公網房間」，成員輸入六位房間碼「加入房間」。
   - 區域網路：同一路由器或已用組網軟體互通的電腦之間使用，房主選擇本機位址，成員填寫房主位址與房間碼。頁面裡有「連線教學」。
   - Cloudflare 公網需要另外設定 cloudflared 元件，包內未附帶。
2. 房主建房後可「複製邀請」傳給成員。
3. **成員表**：房主可以編輯每位成員的組號、順序、身分（樂譜使用者／參與者）與樂器，按住列拖動調整，右鍵或列尾「···」指定總指揮或移出房間。
4. **本機動作**：開啟「操作遊戲」，設定開始方式與停止方式；需要點擊遊戲內按鈕時用「點選按鈕位置」在遊戲視窗上點一下記錄位置。
5. **開奏**：成員按「就緒」，房主按「開始」。倒數結束時工具替每組的樂譜使用者點擊樂譜「使用」或按開始鍵，參與者在遊戲裡依順序加入合奏。
6. **停止**：房主可以取消本輪或全員停止；總指揮演奏結束時可以帶動全員一起停止；成員可用「本機停止」。工具停止失敗時會提示你在遊戲中手動停止。
7. 浮窗裡的「資訊浮窗」元件顯示房間碼、倒數、成員與就緒狀態，解鎖後可直接點「開始」「就緒」。

### 4.4 染色

1. 開啟遊戲的染色介面，綁定遊戲視窗。
2. 三張區域卡各自設定：是否啟用、優先順序、目標色（輸入 HEX、用選色浮層或滴管）、模式（精準 HEX，或相似顏色加 ΔE 容差）以及替代色（最多 63 個）。改動自動儲存。
3. **滴管**：點滴管後工具切到遊戲視窗並擷取整個螢幕，在凍結畫面上左鍵取色，右鍵或 Esc 取消。
4. **選色方案**：把目前設定存成方案，或套用內建的「日系插畫配色」「時尚設計配色」共十套預設。
5. 按「開始」尋色。開始前需要：已綁定遊戲視窗且視窗沒有最小化，程式資料夾裡有完整的 `components\color-engine`（解壓版內附）。條件不滿足時「開始」停用，旁邊寫明缺的是哪一項。開始後工具把遊戲視窗切到前景，擷取遊戲視窗畫面辨識色盤並操作滑鼠；尋色期間請讓遊戲視窗保持在前景、不要移動或縮放視窗，切走或改變視窗會停止這次尋色。選「精準尋色」時工具還會唯讀遊戲記憶體，用戶端版本不受支援時會停止並寫明原因。
6. 執行列的狀態列顯示目前階段與步驟，下面一行說明這一步在做什麼、需要你做什麼（例如「請進入染色介面」），並列出遊戲實測色碼與色差；也顯示剩餘時間與各區域判定。截圖尋色完成一輪後顯示「本輪尋色已完成」，可點「重試」在本局剩餘時間內再找一次；有多個候選時可以選擇。按「停止」或 **F9** 立即停止。
7. 尋色沒有完成時，狀態列寫明結果（例如「遊戲失去焦點，已停止尋色」「無法讀取遊戲程序（權限被拒絕）」「等待染色介面逾時」），說明列給出原因與下一步；精準尋色準備失敗時還寫明停在哪一步。遊戲以系統管理員身分執行時，精準尋色需要以系統管理員身分執行 Moongate。
8. 區域卡的「目前」「實測」是工具在遊戲畫面上讀到的色碼：尋色進行中顯示最新一次讀到的顏色、色差與判定，沒讀出的區域顯示「未讀取」；結束時沒有再次核對遊戲顏色的，「實測」一行標為「上次實測（目前未確認）」，這時請以遊戲目前顏色為準。
9. 浮窗版面裡的「目前顏色」元件在遊戲上方顯示同樣的內容：目前階段與指引、剩餘時間、各區域實測色碼與色差、結果與下一步，有候選時可以選擇；解鎖元件後可以點「停止」或「重試」，上鎖時滑鼠穿透到遊戲。
10. 遊戲和 Moongate 可以放在不同的螢幕上，螢幕縮放為 100%、125%、150% 都可以尋色。
11. **尋色紀錄**保留最近 30 次的結果。

### 4.5 樂譜庫與迷你窗

樂譜庫可以瀏覽樂譜、整理清單與演奏佇列，並開啟迷你窗。台服目前讀不到遊戲內的樂譜內容，遊戲內自動演奏（選曲、換裝、開始演奏、下一首）暫不支援，相關按鈕停用並寫明原因。

### 4.6 浮窗

1. 開啟「浮窗版面」頁，在元件庫裡點一下元件加入目前版面（DPS、技能、比率、自身效果、怪物效果、定時測量、治療、合奏資訊、目前顏色等），在右側調整縮放、外觀（玻璃、純色、自訂圖片）與不透明度。
2. **在螢幕上擺放**：按「螢幕上擺放」卡片的「編輯位置」，元件直接顯示在各螢幕上（包括已關閉的元件），拖曳擺放、拖右下角改尺寸，完成後按螢幕頂部提示列或卡片上的「完成編輯」儲存。
3. **換螢幕**：所選元件詳情裡的「移到顯示器」、卡片上的「全部移到」，或編輯時元件上的箭頭按鈕都可以把元件換到另一個螢幕；「全部移回主顯示器」與「恢復預設位置」用來找回看不見的元件。透過遠端桌面操作、無法直接跨螢幕拖曳時用這些按鈕。
4. 可以儲存多套版面，點「顯示浮窗」在遊戲上方顯示。浮窗每個螢幕一個，置頂且不搶遊戲焦點。
5. 浮窗上每個元件右上角有鎖和關閉按鈕：上鎖後滑鼠穿透到遊戲，解鎖後可以拖曳、改尺寸與操作，停留時還可以用「－／＋」調整縮放、用半圓按鈕調整不透明度。**F8** 顯示或隱藏浮窗，**F7** 全部上鎖或解鎖。
6. 需要遊戲資料而暫不可用的元件放在「需要遊戲資料的元件」裡，並標註原因。
7. 可選「遊戲最小化時隱藏」與「錄影時隱藏」。

### 4.7 模組與擴充

- **已安裝模組**：查看各模組狀態，啟用或停用非核心模組。
- **素材包**：「匯入素材包」選擇一個含 `pack.json` 的資料夾，替換圖示、背景與動效；移除即恢復內建外觀。製作方法見[素材包製作](asset-packs.md)（簡體中文）。
- **擴充模組**：「安裝擴充模組」選擇 `.zip`，先顯示檢查結果（識別碼、版本、發布者、檔案數、大小、簽章狀態），確認後安裝。帶程式的擴充還會列出執行方式、申請的一般權限與高風險權限、存取的主機。安裝的擴充預設停用，可隨時啟用、停用或解除安裝。也可以把 `.zip` 放進擴充資料夾的 `inbox` 裡，在頁面上逐個檢查安裝。
- **權限**：一般權限（讀取資料、提供頁面與浮窗元件等）在確認安裝時授予；截圖、連網、讀取檔案、操作遊戲等高風險權限預設關閉，在擴充卡片上逐項按「授予」開啟，隨時可以「撤銷」，撤銷立即生效。
- **執行狀態與日誌**：帶程式的擴充在獨立程序裡執行，卡片顯示執行狀態；出錯時可以按「重新啟動」，按「日誌」檢視最近的輸出。擴充提供的頁面在側欄「擴充」分組裡，浮窗元件在浮窗版面頁的元件庫裡，設定項在設定頁「擴充」卡片裡。
- 擴充程式以目前 Windows 使用者身分執行，請只安裝信任來源的擴充。製作方法見[擴充模組開發](extensions.md)（簡體中文）。

### 4.8 診斷

- **執行狀態**：背景各部分的狀態，可「複製全部」。
- **最近紀錄**：依模組與層級篩選。
- **除錯採集**：限時記錄更詳細的執行資訊，開始前會說明收集範圍。
- **匯出排查包**：把診斷資訊打包儲存，用於回報問題。

## 5. 快速鍵

| 快速鍵 | 作用 |
|---|---|
| F9 | 緊急停止工具送出的遊戲輸入（合奏、染色） |
| F8 | 顯示或隱藏浮窗 |
| F7 | 浮窗元件全部上鎖或解鎖 |
| 未指定 | 開始／取消定時測量（可在設定裡指定） |

快速鍵在設定頁修改，點錄入框後按新組合，Esc 取消。

## 6. 資料位置、升級與解除安裝

所有檔案都在工具資料夾內：

| 位置 | 內容 |
|---|---|
| `Moongate.exe` | 啟動入口 |
| `components` | 程式本體與隨包執行環境 |
| `licenses` | 第三方聲明（`THIRD_PARTY_NOTICES.txt`，含本專案 MIT 授權）與元件清單 `sbom.spdx.json` |
| `userdata\data` | 資料庫、設定、記錄檔、診斷、備份、擴充模組（第一次執行後出現，下同） |
| `userdata\desktop` | 介面偏好、浮窗版面、背包備註、效果收藏、素材包 |
| `userdata\bootstrap`、`userdata\runtime` | 啟動設定與執行中的實例資訊 |

**程式內更新。** 設定頁「更新」卡片顯示目前版本、發現的新版本與大小、下載進度和上次安裝結果。發現新版本後點「下載更新」，下載並校驗完成後點「安裝並重新啟動」：正在演奏、染色、定時測量或在房間裡時會先等這些活動結束；隨後 Moongate 關閉，替換程式檔案後自動開啟新版本。新版本沒能正常啟動時會自動回到原來的版本並復原資料，設定頁寫明原因。工具只從本專案的 GitHub Releases 下載，核對 SHA-256 與壓縮檔內容後才安裝，不會降級。

**手動升級。** 把新版本的壓縮檔解壓縮到一個新資料夾，關閉 Moongate，把舊資料夾裡的 `userdata` 整個移到新資料夾裡（與新的 `Moongate.exe` 放在一起），再執行新的 `Moongate.exe`；確認正常後刪除舊資料夾。也可以在關閉 Moongate 後，用新包裡的 `components`、`licenses` 與 `Moongate.exe` 取代舊資料夾裡的同名三項。自動更新失敗且舊版本也無法開啟時，工具會彈出同樣的步驟。

解除安裝時先關閉 Moongate 視窗，再刪除整個資料夾即可。

## 7. 常見問題

**抓包狀態寫「未安裝 Npcap」。** 安裝 Npcap 後不需重新啟動，工具每隔 5–60 秒自動重試，約一分鐘內開始抓包；也可以在設定裡把自動抓包關閉再開啟立即重試。

**裝了 Npcap 仍然抓不到資料。** 使用 VPN、加速器或多張網路卡時，工具會先自動檢測約 10 秒找出遊戲使用的網卡（狀態顯示「（自動檢測）」），期間請在遊戲裡移動角色。仍找不到時，到設定頁的抓包部分點「列出網卡」查看遊戲連線在哪張網卡，或用「開始檢測」後確認使用該網卡。

**遊戲更新後。** 工具會讀取本機的新版遊戲檔案自動核對，核對期間顯示「正在核對新版遊戲」，通過後照常抓包，狀態寫「已適配新版遊戲」。某項功能的資料格式在新版裡有變化時，只停用這一項並寫明（例如「新版遊戲：戰鬥統計暫停用」），其他功能照常；等工具更新後恢復。

**合奏頁沒辨識出我的角色。** 確認正在抓包後，在遊戲裡切換一次地圖。

**背包一直顯示「未讀取」。** 背包資料在角色登入時下發。開著 Moongate 抓包時重新登入角色。

**啟動時提示無法寫入。** 工具資料夾沒有寫入權限。把整個資料夾移到 `D:\Moongate` 這類一般位置。

**按兩下後沒有視窗，或提示背景服務啟動失敗。** 在工具資料夾開啟終端機執行 `components\core\launch-backend.cmd -Wait`，視窗會顯示背景服務的啟動輸出與失敗原因。在壓縮檔檢視器裡直接執行時，工具會提示先完整解壓縮。

**底部顯示「未連接後端」。** 底部狀態與設定頁「後端」卡片的「連接」一行寫有原因。寫著「本機連接埠 19998 已被佔用」時，是另一個資料夾裡的 Moongate 仍在執行（解壓縮了兩份，或舊的一份沒結束就開啟了新的一份）：關閉那一份的 Moongate 視窗，或在工作管理員的「詳細資料」裡結束命令列含 MabiTool.Host 的 dotnet.exe，然後重新開啟。19998 被其他軟體佔用或被系統保留時 Moongate 會自動改用空閒連接埠，不需要處理，設定頁「後端」卡片的「位址」一行顯示實際連接埠。其他原因依提示處理，或執行上一條的 `launch-backend.cmd -Wait` 查看。

**怎樣完全結束。** 關閉 Moongate 視窗即可：背景服務隨視窗一起結束，正在進行的合奏演奏、染色與定時測量會停止並釋放遊戲操作，不留背景程序。視窗開著時再次按兩下 `Moongate.exe` 只會把視窗帶到前景。背景服務意外停止時底部狀態寫「後端已停止」，Moongate 會自動重新啟動它一次；再次停止時請關閉並重新開啟 Moongate。

**工具點不動遊戲。** 遊戲以系統管理員身分執行時，Moongate 也需要以系統管理員身分執行。

**浮窗擋住了遊戲操作。** 按 F7 把全部元件上鎖，滑鼠即可穿透到遊戲；或按 F8 隱藏浮窗。

**想回報問題。** 在「診斷」頁匯出排查包，連同重現步驟提交到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。
