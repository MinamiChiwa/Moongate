> **測試版提示**
>
> Moongate 仍屬於測試版：各項功能已經可以使用，但可能還有問題。遇到問題或有建議，歡迎到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues) 回報。

**這一版修了什麼：** 遊戲在 11 月 18 日更新後，0.1.0 會顯示「遊戲版本未核驗」，戰鬥統計、背包和合奏識別全部停止。0.1.1 已支援更新後的遊戲；之後遊戲再更新時，Moongate 會自己核對新版遊戲並繼續運作，不用等新版本。**正在使用 0.1.0 的請升級到這一版。**

**下載哪個檔案：** 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的 v0.1.1 發行下方 Assets 裡，下載排在最上面的 **`Moongate-v0.1.1-Windows-x64.zip`**（約 170 MB，解壓縮後約 430 MB）。完整解壓縮到一個一般資料夾（例如 `D:\Moongate`），按兩下裡面的 **`Moongate.exe`** 即可執行。

**從 0.1.0 升級：** 在設定頁「更新」裡點「檢查更新」，「下載更新」後點「安裝並重新啟動」。也可以手動升級：把新版本解壓縮到一個新資料夾，關閉 Moongate，把舊資料夾裡的 `userdata` 整個移到新資料夾，再執行新的 `Moongate.exe`。

| 檔案 | 用途 |
|---|---|
| `Moongate-v0.1.1-Windows-x64.zip` | 正式包，下載這一個即可 |
| `Moongate-v0.1.1-Windows-x64.zip.sha256` | 正式包的 SHA-256 校驗值，用來核對下載是否完整，一般使用者不用下載 |
| Source code (zip / tar.gz) | GitHub 自動附上的原始碼，一般使用者不用下載 |

## 這一版的變化

- **支援 11 月 18 日更新後的遊戲**：戰鬥統計、背包、合奏識別在更新後的用戶端上恢復正常。
- **遊戲更新後自動適配**：遇到沒見過的遊戲版本時，Moongate 先核對新版遊戲（狀態顯示「正在核對新版遊戲，稍後自動開始」，約幾秒），通過後照常運作並顯示「已適配新版遊戲」。如果某一項功能在新版遊戲裡對不上，只停用那一項並寫明原因（例如「新版遊戲：戰鬥統計暫停用」），其他功能不受影響。
- **自動找到遊戲所在的網卡**：使用 VPN、加速器或電腦有多張網卡時，Moongate 會用約 10 秒觀察流量來確定遊戲連線所在的網卡，狀態裡標註「（自動檢測）」；檢測期間在遊戲裡走動幾步更容易判定。設定頁「列出網卡」會直接寫明遊戲連線在哪張網卡上。確實判定不出時，才需要在設定頁手動檢測或指定。
- **排查包更有用**：匯出的排查包會記錄遊戲版本核對結果、抓包為什麼沒有開始、選中了哪張網卡，回報問題時更容易定位。

## 已知問題與限制

- 遊戲開著、工具無人操作時，背景服務在部分電腦上仍佔用約 0.2 個 CPU 核心，後續版本繼續最佳化。
- 遊戲視窗正在被拖曳或調整大小時，在設定頁手動點「開始檢測」可能提示綁定已變化，等視窗停穩後再點一次即可。
- 其餘已知問題與 0.1.0 相同，見 [0.1.0 更新說明](release-notes-0.1.0.zh-TW.md)，其中「可能需要手動選擇網卡」一條已在這一版改善。
