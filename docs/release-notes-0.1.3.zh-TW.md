> **測試版提示**
>
> Moongate 仍屬於測試版：各項功能已經可以使用，但可能還有問題。遇到問題或有建議，歡迎到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues) 回報。

**這一版修了什麼：** 開著加速器時抓不到遊戲資料（狀態顯示抓包中，但 DPS、背包、合奏都沒有內容）的問題；部分電腦上「後端未能啟動：資料目錄不可用」且重新啟動、換位置都無效的問題；精準尋色在其他電腦上一直卡在識別色卡的問題。**開加速器玩遊戲的請升級到這一版。**

**下載哪個檔案：** 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的 v0.1.3 發行下方 Assets 裡，下載排在最上面的 **`Moongate-v0.1.3-Windows-x64.zip`**（約 170 MB，解壓縮後約 430 MB）。完整解壓縮到一個一般資料夾（例如 `D:\Moongate`），按兩下裡面的 **`Moongate.exe`** 即可執行。

**從舊版本升級：** 0.1.2 可以在設定頁「更新」裡「檢查更新」後「安裝並重新啟動」，這一次是增量更新，只下載有變化的檔案。0.1.0、0.1.1 或者後端啟動不了的，請手動升級：下載上面的正式包解壓縮，把裡面的檔案覆蓋到原來的 Moongate 資料夾（保留 `userdata`），再執行 `Moongate.exe`。

| 檔案 | 用途 |

| `Moongate-v0.1.3-Windows-x64.zip` | 正式包，下載這一個即可 |
| `Moongate-v0.1.3-Windows-x64.zip.manifest.json` | 應用程式內更新使用的檔案清單，不用下載 |

## 這一版的變化

### 抓包

- **開著加速器也能抓到資料**：Moongate 不再挑一張網卡來抓，而是同時監聽電腦上所有網卡（包括加速器的虛擬網卡和本機迴環），只認遊戲自己的連線。不管加速器是哪一款、用哪種方式接管遊戲流量，都不需要手動選網卡，也不需要關閉加速器。
- **狀態更明確**：抓包狀態會寫明資料來自哪裡，例如「來源：實體網卡」「來源：隧道（加速器）」「來源：迴環（加速器）」。約 20 秒收不到遊戲資料時顯示「收不到遊戲資料」；有資料但還沒識別出角色時顯示「等待角色資訊，請切換一次地圖」。
- **指定網卡立即生效**：在設定裡指定網卡或切回自動後，抓包會馬上按新設定重新開始。
- 支援 IPv6 連線；中文網卡名不再顯示亂碼。

### 啟動

- **「資料目錄不可用」的幾種情況已修復**：以系統管理員身分執行、程式放在行動硬碟或隨身碟、檔案帶唯讀屬性、安全軟體改動了檔案權限時，後端現在可以正常啟動。
- **第一次啟動中途失敗後可以復原**：以前第一次啟動被打斷（校驗失敗、被安全軟體結束、斷電）後，這個資料夾就再也啟動不了。現在再開啟一次會接著完成，不需要刪除 `userdata`。
- **啟動失敗會說明原因**：「未連接後端」下面直接顯示具體原因和做法（例如「寫入被系統安全防護攔截／移出桌面，或在安全中心允許 Moongate」）。後端沒啟動時，診斷頁也可以「匯出啟動記錄」用來回報。

### 染色

- **精準尋色不再無提示地卡住**：識別色卡沒通過時，會寫明原因和做法——色卡被其他視窗遮擋、文字識別逾時、色碼或色塊讀數不一致等，並提示可以改用截圖尋色。
- **尋色時 Moongate 自己的視窗不會干擾識別**：蓋在遊戲畫面上的 Moongate 視窗在尋色期間不進入截圖。注意：這些視窗在尋色期間也不會出現在錄影和遠端桌面畫面裡，移開遊戲畫面即可恢復。
- 遊戲全螢幕且解析度低於顯示器、工具路徑裡有中文、Windows N 版本缺少媒體功能套件、遊戲更換引擎版本這幾種情況，分別做了適配或給出專門提示。

### 其他

- 遊戲以系統管理員身分執行而 Moongate 沒有時，會提示「請以系統管理員身分執行 Moongate」，不再顯示「處理程序已變化」。
- 遊戲安裝目錄用連結遷移到其他磁碟時，戰鬥統計和背包可以正常識別。
- 主視窗會按螢幕大小調整，1366×768 或高縮放的筆電上不再超出螢幕。
- 較慢的電腦、傳統硬碟或防毒軟體掃描時，不再因為等待時間太短而誤判為啟動失敗或元件斷線。
- 開著系統 Proxy 時，Moongate 與自己後端的連線、區域網路合奏都不再受 Proxy 影響；區域網路房間連不上時會提示檢查防火牆。
- 新角色（技能欄為空）登入後可以讀到錢包。
- 系統版本低於 Windows 10 1703 時啟動器會給出說明。

## 已知問題與限制

- 遊戲開著、工具無人操作時，背景服務在部分電腦上仍佔用約 0.2 個 CPU 核心，後續版本繼續最佳化。
- 加速器種類很多，這一版按遊戲連線而不是加速器型號來識別，但沒有在每一款上實測。仍然收不到資料時，請在遊戲裡停留約 30 秒後到「診斷」頁匯出排查包回報，裡面會記錄每張網卡收到了什麼。
- 遊戲視窗由系統代為縮放（遊戲不支援高縮放顯示器）時，背景觸控輸入暫時停用，前景輸入不受影響。
- 其餘已知問題見 [0.1.0 更新說明](release-notes-0.1.0.zh-TW.md)。
