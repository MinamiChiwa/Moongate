> **测试版提示**
>
> Moongate 仍属于测试版：各项功能已经可以使用，但可能还有问题。遇到问题或有建议，欢迎到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues) 反馈。

**这一版的重点：** 修复战斗数据中断与不完整（地下城重试进图后没有数据、野外首领战数据缺失）；DPS 浮窗新增怪物血量，首领血量也能显示；战斗记录可以打开明细；占用的内存和 CPU 明显降低；战斗属性改用游戏自带的图标。

**下载哪个文件：** 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的 v0.1.5 发行下方 Assets 里，下载排在最上面的 **`Moongate-v0.1.5-Windows-x64.zip`**（约 170 MB，解压后约 430 MB）。完整解压到一个普通文件夹（例如 `D:\Moongate`），双击里面的 **`Moongate.exe`** 即可运行。

**从旧版本升级：** 在设置页“更新”里“检查更新”后“安装并重启”。0.1.4 只下载有变化的文件；0.1.3 及更早的版本是完整下载。也可以手动升级：下载上面的正式包解压，把里面的文件覆盖到原来的 Moongate 文件夹（保留 `userdata`），再运行 `Moongate.exe`。

| 文件 | 用途 |
|---|---|
| `Moongate-v0.1.5-Windows-x64.zip` | 正式包，下载这一个即可 |
| `Moongate-v0.1.5-Windows-x64.zip.manifest.json` | 应用内更新使用的文件清单，不用下载 |
| `Moongate-v0.1.5-Windows-x64.zip.sha256` | 正式包的 SHA-256 校验值，用来核对下载是否完整，普通用户不用下载 |
| Source code (zip / tar.gz) | GitHub 自动附带的源代码，普通用户不用下载 |

## 这一版的变化

### 战斗统计

- **地下城重试进图后不再没有数据**：游戏在加载时重建窗口，以前会被当成换了一个游戏，抓包随之中断，要到下次换图才恢复。现在只要游戏进程还在就持续抓包。
- **野外首领战数据不再缺失**：人多、连接频繁变化时，以前会不断丢失一小段数据，每丢一次战斗分段就结束一次。丢数据的原因已修复；即使偶尔缺了一小段，分段也不再结束，只在该分段和记录上标注“数据不完整”。
- **怪物血量**：DPS 浮窗和 DPS 检测页显示当前攻击目标的名称、血量槽、当前值／最大值和百分比，首领的血量同样可以显示。显示哪只怪由你在游戏里选中的目标和最近的攻击决定。需要在首领出现之后才打开工具的情况下，血量会显示“未读取”，重新进入首领视野后恢复。
- **战斗记录可以打开明细**：记录列表每一行新增“明细”，打开与实时明细相同的窗口（技能、目标、各项比率、元素、治疗、DPS 曲线），可以同时打开四条记录对比。
- **“未知”怪物减少**：抓包中途重新开始后仍记得已经见过的怪物；名称晚一步读到时会补上；NPC、宠物、召唤物等现在也显示名称。客户端里本身没有名字的怪物显示“客户端名称为空”。
- **战斗属性改用游戏自带图标**：暴击、强击、连击、追击、无防备、破防、多重打击和八种元素在 DPS 页、明细窗口和浮窗上显示为图标，悬停可看名称。图标从你电脑上的游戏客户端读取，读不到时显示文字。
- 抓包重新开始后，如果还在原来那张地图，会沿用已识别的角色；换了地图则提示“角色待确认，请切换一次地图”。

### 性能

- 抓包组件处理同样的数据，CPU 降到原来的约六成，内存分配减半；没有游戏数据时几乎不占用 CPU。
- 后端在战斗中停手、切到城镇等空闲状态下的 CPU 和写盘大幅减少；启动时读取游戏文件的内存峰值从约 260 MB 降到约 40 MB。
- 界面只读取当前看得见的页面和浮窗需要的数据，主窗口最小化时基本不再向后端请求。

### 浮窗与界面

- **浮窗不透明度分成两项**：“背景”和“内容”可以分别调整，背景可以调到完全透明而文字仍清晰。
- 浮窗边框改为更淡的玻璃细边。
- 按钮悬停放大时不再被边缘裁切。
- 合奏页切换昵称来源时，右侧联机方式开关不再被拉长。
- **动效开关以你的选择为准**：系统关闭了动画效果（例如使用远程桌面）时，只要在设置里选了“开启”，动效仍然生效。

### 其他修复

- 关闭自动抓包后手动开始的抓包，现在会在不再需要时停止。
- 扩展模块启动时偶尔被误判为违规而失败的问题。
- 设置里指定的网卡已不存在时，自动改用全部网卡并在状态里说明。
- 抓包出现故障时诊断里会写明具体类别，并在几秒内自动重试。

## 已知问题与限制

- 首领血量需要工具看到首领出现的那一刻；之后才打开工具时显示“未读取”，重新进入首领视野后恢复。
- 有的怪物服务器不单独下发血量（例如与另一只首领共用血量），这时显示同场首领的血量并标注“同场首领”。
- 浮窗上锁（鼠标穿透）时看不到图标的悬停名称，可在“浮窗版面”页选中元件查看图标对照。
- 寻色期间盖在游戏画面上的 Moongate 窗口不会出现在截图、录屏和远程桌面画面里，移开即可恢复。
- 其余已知问题见 [0.1.3 更新说明](release-notes-0.1.3.md)与 [0.1.0 更新说明](release-notes-0.1.0.md)。
