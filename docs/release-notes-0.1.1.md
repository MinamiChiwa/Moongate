> **测试版提示**
>
> Moongate 仍属于测试版：各项功能已经可以使用，但可能还有问题。遇到问题或有建议，欢迎到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues) 反馈。

**这一版修了什么：** 游戏在 11 月 18 日更新后，0.1.0 会显示“游戏版本未核验”，战斗统计、背包和合奏识别全部停止。0.1.1 已支持更新后的游戏；以后游戏再更新时，Moongate 会自己核对新版游戏并继续工作，不用等新版本。**正在使用 0.1.0 的请升级到这一版。**

**下载哪个文件：** 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的 v0.1.1 发行下方 Assets 里，下载排在最上面的 **`Moongate-v0.1.1-Windows-x64.zip`**（约 170 MB，解压后约 430 MB）。完整解压到一个普通文件夹（例如 `D:\Moongate`），双击里面的 **`Moongate.exe`** 即可运行。

**从 0.1.0 升级：** 在设置页“更新”里点“检查更新”，“下载更新”后点“安装并重启”。也可以手动升级：把新版本解压到一个新文件夹，关闭 Moongate，把旧文件夹里的 `userdata` 整个移到新文件夹，再运行新的 `Moongate.exe`。

| 文件 | 用途 |
|---|---|
| `Moongate-v0.1.1-Windows-x64.zip` | 正式包，下载这一个即可 |
| `Moongate-v0.1.1-Windows-x64.zip.sha256` | 正式包的 SHA-256 校验值，用来核对下载是否完整，普通用户不用下载 |
| Source code (zip / tar.gz) | GitHub 自动附带的源代码，普通用户不用下载 |

## 这一版的变化

- **支持 11 月 18 日更新后的游戏**：战斗统计、背包、合奏识别在更新后的客户端上恢复正常。
- **游戏更新后自动适配**：遇到没见过的游戏版本时，Moongate 先核对新版游戏（状态显示“正在核对新版游戏，稍后自动开始”，约几秒），通过后照常工作并显示“已适配新版游戏”。如果某一项功能在新版游戏里对不上，只停用那一项并写明原因（例如“新版游戏：战斗统计暂停用”），其他功能不受影响。
- **自动找到游戏所在的网卡**：使用 VPN、加速器或电脑有多张网卡时，Moongate 会用约 10 秒观察流量来确定游戏连接所在的网卡，状态里标注“（自动检测）”；检测期间在游戏里走动几步更容易判定。设置页“列出网卡”会直接写明游戏连接在哪张网卡上。确实判定不出时，才需要在设置页手动检测或指定。
- **排查包更有用**：导出的排查包会记录游戏版本核对结果、抓包为什么没有开始、选中了哪张网卡，反馈问题时更容易定位。

## 已知问题与限制

- 游戏开着、工具无人操作时，后台服务在部分电脑上仍占用约 0.2 个 CPU 核心，后续版本继续优化。
- 游戏窗口正在被拖动或调整大小时，在设置页手动点“开始检测”可能提示绑定已变化，等窗口停稳后再点一次即可。
- 其余已知问题与 0.1.0 相同，见 [0.1.0 更新说明](release-notes-0.1.0.md)，其中“可能需要手动选择网卡”一条已在这一版改善。
