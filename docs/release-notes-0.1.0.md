## 这一版能做什么

Moongate 是《瑪奇 Mobile》台服的 Windows 桌面工具。它读取本机的游戏网络数据来识别角色、伤害、背包和演奏状态，并在你开启相应功能时替你操作游戏窗口。

- **战斗统计（DPS检测）**：自动统计总伤害、DPS、对每个目标的伤害与你的贡献占比，暴击、强击、连击、追击比率，元素构成，按技能与按目标的明细；治疗量、HPS 与受到治疗的有效比例；自身与怪物身上的效果（Buff）层数与剩余时间，可收藏常看的效果；破防期间的伤害与时间占比。
- **整场与分段**：切换地图或脱离战斗 3 分钟后，这一场结束并保留为“上一场”，下次造成伤害时开始新的一场；怪物清完后 10 秒内接着打仍算同一个分段，也可以手动拆段。“重设”一键清空整场、分段与定时测量。
- **定时测量与记录**：设定时长（例如 1 分钟），从首次伤害开始计时，结束后列出 DPS 与总伤害；可以给结果命名保存。明细可以在独立窗口里查看，DPS 曲线悬停显示时间与数值。
- **背包与保管箱**：角色登录时自动读取背包、角色保管箱与公共保管箱的全部类别，同一账号的多个角色合并成一张表，没读到的地方写“未读取”。乐谱每张一行并显示谱名，悬停可见作曲与编曲。概况显示金币、银币与魔族貢品，银币和贡品显示下一次补充的倒计时。支持备注、搜索、导出 CSV 和独立窗口。
- **合奏**：服务器直连（六位房间码）或局域网建房，成员分组与顺序，统一倒计时后由工具同时点下乐谱“使用”或开始键，也可以一起做表情动作；总指挥演奏结束时全员到点一起停止，成员也可以只停止自己。“信息浮窗”在游戏上方显示房间码、倒计时与就绪状态，可以直接点“开始”“就绪”。
- **染色**：三个区域分别设定目标色（精准 HEX 或相似颜色加容差）与替代色，用屏幕吸管取色，保存选色方案或套用十套内置配色。支持截图寻色与精准寻色，显示实测色码、色差与候选方案，可以重试；保留最近 30 次寻色记录。游戏与 Moongate 可以放在不同显示器上，显示器缩放 100%、125%、150% 都能寻色。“当前颜色”浮窗在游戏上方逐步提示该做什么。
- **游戏浮窗**：DPS、技能、比率、效果、定时测量、治疗、合奏信息、当前颜色等元件可以摆在任意显示器上。“编辑位置”后直接在屏幕上拖动、改尺寸，也可以用“移到显示器”换屏。每个元件可以单独上锁（鼠标穿透到游戏）、调整缩放与不透明度；可保存多套版面，F8 显示或隐藏，F7 全部上锁或解锁。
- **扩展模块**：导入素材包替换图标、背景与动效；安装第三方扩展模块（ZIP）。带程序的扩展在独立进程里运行，可以提供页面、浮窗元件、设置项和快捷键；普通权限安装时授予，截图、联网、读取文件、操作游戏等高风险权限默认关闭，由你逐项打开。仓库附带一个击杀计时器示例。
- **应用内更新**：设置页“更新”里可以检查、下载并“安装并重启”。只从本项目的 GitHub Releases 下载，核对 SHA-256 后整包替换；新版本启动失败时自动回到原版本，`userdata` 里的数据保留。
- **界面**：简体中文与繁體中文，浅色与深色主题；侧栏模块可以拖动排序；各页的说明收在标题旁的问号里，悬停或点按查看。读不到的数据显示“未读取”“未知”，不会用 0 代替。
- **诊断**：查看运行状态与最近记录，一键导出排查包，方便反馈问题。

各功能的操作步骤见[使用说明](user-guide.md)。

### 暂不支持

- **游戏内自动演奏**：乐谱库可以浏览乐谱、整理清单与演奏队列，但台服目前读不到游戏内的乐谱内容，自动选曲、换装、开始与停止演奏暂不可用，相关按钮停用并写明原因。
- **需要游戏内时间、天气、附近演奏的浮窗元件**：标注“台服暂不支持”。
- **合奏的 Cloudflare 公网方式**：需要另行配置 cloudflared，包内没有附带；服务器直连与局域网可以直接使用。
- **从本地压缩包更新**：应用内更新只从 GitHub Releases 下载；离线时请按下方“手动升级”操作。

## 使用前须知

- **适用范围**：只支持《瑪奇 Mobile》台服，Windows 10 / 11 64 位。
- **需要自行安装 Npcap**：Moongate 用 Npcap 读取游戏网络数据，它不随工具附带。请从 [Npcap 官方下载页](https://npcap.com/#download)下载安装，保持默认选项即可；没装时工具会弹出安装指引，装好后约一分钟内自动开始，不需要重启工具。.NET、Python 与文字识别组件都已包含在包内。
- **账号风险**：Moongate 是非官方工具，与 NEXON、devCAT 及台服营运方无关。它读取游戏网络数据，开启合奏、染色或扩展的输入权限时会自动操作游戏；精准寻色还会只读游戏内存，风险更高。这些行为可能不符合游戏服务条款，是否使用请自行判断，账号因此受到的处置由使用者自行承担。
- **首次运行的 Windows 提示**：程序没有代码签名，Windows 可能显示“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
- **数据都在程序文件夹里**：设置、浮窗版面、备注、记录和数据库都保存在程序文件夹里的 `userdata`，不写入 AppData 或注册表。整个文件夹可以移动、改名或复制到别的电脑，数据跟着走；卸载时关闭 Moongate，直接删除整个文件夹即可。
- **放置位置**：放在你有写入权限的普通文件夹，不要放在 `C:\Program Files`、OneDrive 同步目录或网络磁盘里。在压缩包查看器里直接双击无法运行，请先完整解压。
- **退出**：关闭 Moongate 窗口，后台服务随之退出，不留后台进程。游戏以管理员身份运行时，Moongate 也需要以管理员身份运行才能操作游戏。

## 已知问题与限制

- 游戏开着、工具无人操作时，后台服务在部分电脑上仍占用约 0.2 个 CPU 核心，后续版本继续优化。
- 地图名在进图后才显示，刚开始抓包时在游戏里切换一次地图即可；频道显示客户端的频道序号，副本内显示“副本频道”。
- 背包数据在角色登录时下发，工具启动前已在游戏中的角色需要重新登录一次。
- 治疗统计中药水、自我治疗以及对队友或宠物施放的治疗仍在核对，个别数值可能与游戏内不一致。
- 染色已在显示器缩放 100%、125%、150% 下核对，其他缩放比例尚未核对。
- 经远程桌面操作时，浮窗元件可能无法直接拖到另一块屏幕，请用浮窗版面页的“移到显示器”或浮窗上的箭头按钮换屏。
- 使用 VPN、加速器或多张网卡时，可能需要在设置页的抓包部分手动选择网卡。

## 升级与反馈

- **以后的升级**：在设置页“更新”里点“检查更新”，发现新版本后“下载更新”，再点“安装并重启”。正在合奏、染色或定时测量时会等这些活动结束再安装。
- **手动升级**：把新版本解压到一个新文件夹，关闭 Moongate，把旧文件夹里的 `userdata` 整个移到新文件夹（与新的 `Moongate.exe` 放在一起），再运行新的 `Moongate.exe`。
- **反馈问题**：在“诊断”页导出排查包，连同问题描述与复现步骤提交到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。
