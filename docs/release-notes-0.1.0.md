## 已知限制

- **游戏内自动演奏**尚未实现，乐谱库里的“游戏内演奏”入口停用。附近演奏、游戏内时间与天气等需要游戏数据的浮窗元件标注“台服暂不支持”。
- **地图与频道**在抓包收到进图通知后才显示，刚开始抓包时在游戏里切换一次地图即可。频道号取客户端的频道序号，副本内显示“副本频道”。
- **合奏 Cloudflare 公网方式**需要另行配置 cloudflared，预览包未附带；服务器直连与局域网可直接使用。
- **扩展模块**只支持纯数据扩展（图片、文字与数据文件）；带程序的扩展会被拒绝安装。
- **数字签名**：预览包未签名，Windows SmartScreen 可能提示，选择“仍要运行”即可。
- **抓包**依赖 Npcap，使用 VPN、加速器或多网卡时可能需要在设置里手动选择网卡。
