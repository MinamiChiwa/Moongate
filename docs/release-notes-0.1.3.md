> **测试版提示**

> Moongate 仍属于测试版：各项功能已经可以使用，但可能还有问题。遇到问题或有建议，欢迎到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues) 反馈。

**这一版修了什么：** 开着加速器时抓不到游戏数据（状态显示抓包中，但 DPS、背包、合奏都没有内容）的问题；部分电脑上“后端未能启动：数据目录不可用”且重启、换位置都无效的问题；精准寻色在其他电脑上一直卡在识别色卡的问题。**开加速器玩游戏的请升级到这一版。**

**下载哪个文件：** 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的 v0.1.3 发行下方 Assets 里，下载排在最上面的 **`Moongate-v0.1.3-Windows-x64.zip`**（约 170 MB，解压后约 430 MB）。完整解压到一个普通文件夹（例如 `D:\Moongate`），双击里面的 **`Moongate.exe`** 即可运行。

**从旧版本升级：** 0.1.2 可以在设置页“更新”里“检查更新”后“安装并重启”，这一次是增量更新，只下载有变化的文件。0.1.0、0.1.1 或者后端启动不了的，请手动升级：下载上面的正式包解压，把里面的文件覆盖到原来的 Moongate 文件夹（保留 `userdata`），再运行 `Moongate.exe`。

## 这一版的变化

### 抓包

- **开着加速器也能抓到数据**：Moongate 不再挑一张网卡来抓，而是同时监听电脑上所有网卡（包括加速器的虚拟网卡和本机回环），只认游戏自己的连接。不管加速器是哪一款、用哪种方式接管游戏流量，都不需要手动选网卡，也不需要关闭加速器。
- **状态更明确**：抓包状态会写明数据来自哪里，例如“来源：物理网卡”“来源：隧道（加速器）”“来源：回环（加速器）”。约 20 秒收不到游戏数据时显示“收不到游戏数据”；有数据但还没识别出角色时显示“等待角色信息，请切换一次地图”。
- **指定网卡立即生效**：在设置里指定网卡或切回自动后，抓包会马上按新设置重新开始。
- 支持 IPv6 连接；中文网卡名不再显示乱码。

### 启动

- **“数据目录不可用”的几种情况已修复**：以管理员身份运行、程序放在移动硬盘或 U 盘、文件带只读属性、安全软件改动了文件权限时，后端现在可以正常启动。
- **第一次启动中途失败后可以恢复**：以前第一次启动被打断（校验失败、被安全软件结束、断电）后，这个文件夹就再也启动不了。现在再打开一次会接着完成，不需要删除 `userdata`。
- **启动失败会说明原因**：“未连接后端”下面直接显示具体原因和做法（例如“写入被系统安全防护拦截 / 移出桌面，或在安全中心允许 Moongate”）。后端没启动时，诊断页也可以“导出启动记录”用来反馈。

### 染色

- **精准寻色不再无提示地卡住**：识别色卡没通过时，会写明原因和做法——色卡被其他窗口遮挡、文字识别超时、色码或色块读数不一致等，并提示可以改用截图寻色。
- **寻色时 Moongate 自己的窗口不会干扰识别**：盖在游戏画面上的 Moongate 窗口在寻色期间不进入截图。注意：这些窗口在寻色期间也不会出现在录屏和远程桌面画面里，移开游戏画面即可恢复。
- 游戏全屏且分辨率低于显示器、工具路径里有中文、Windows N 版本缺少媒体功能包、游戏更换引擎版本这几种情况，分别做了适配或给出专门提示。

### 其他

- 游戏以管理员身份运行而 Moongate 没有时，会提示“请以管理员身份运行 Moongate”，不再显示“进程已变化”。
- 游戏安装目录用链接迁移到其他盘时，战斗统计和背包可以正常识别。
- 主窗口会按屏幕大小调整，1366×768 或高缩放的笔记本上不再超出屏幕。
- 较慢的电脑、机械硬盘或杀毒软件扫描时，不再因为等待时间太短而误判为启动失败或组件断开。
- 开着系统代理时，Moongate 与自己后端的连接、局域网合奏都不再受代理影响；局域网房间连不上时会提示检查防火墙。
- 新角色（技能栏为空）登录后可以读到钱包。
- 系统版本低于 Windows 10 1703 时启动器会给出说明。

## 已知问题与限制

- 游戏开着、工具无人操作时，后台服务在部分电脑上仍占用约 0.2 个 CPU 核心，后续版本继续优化。
- 加速器种类很多，这一版按游戏连接而不是加速器型号来识别，但没有在每一款上实测。仍然收不到数据时，请在游戏里停留约 30 秒后到“诊断”页导出排查包反馈，里面会记录每张网卡收到了什么。
- 游戏窗口由系统代为缩放（游戏不支持高缩放显示器）时，后台触控输入暂时停用，前台输入不受影响。
- 其余已知问题见 [0.1.0 更新说明](release-notes-0.1.0.md)。
