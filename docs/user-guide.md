# Moongate 使用说明

[简体中文](user-guide.md) · [繁體中文](user-guide.zh-TW.md) · [返回首页](../README.md)

本说明对应 Moongate 0.1.9（测试版）。这一版的变化与已知问题见[更新说明](release-notes-0.1.9.md)。

## 1. 准备

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 1703 或更新版本 / Windows 11，64 位（系统自带的 .NET Framework 4.x 即可，无需另装） |
| 游戏 | 《瑪奇 Mobile》台服 Windows 客户端 |
| Npcap | 抓包必需，需自行安装：[npcap.com](https://npcap.com/#download)。安装时保持默认选项即可 |
| 放置位置 | 你有写入权限的普通文件夹，例如 `D:\Moongate`；不要放在 `C:\Program Files`、OneDrive 同步目录或网络磁盘 |
| 游戏连接器 | 角色、交易所、背包估价、生活的采集加工制作、乐谱库游戏内演奏与合奏换乐器需要；包内附带，默认关闭，启用方法见 [4.1](#41-游戏连接器) |

在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的最新版本下方 Assets 里下载排在最上面的 `Moongate-v0.1.9-Windows-x64.zip`（约 175 MB，解压后约 450 MB），完整解压后运行 `Moongate.exe`。同一发行里的 `.sha256` 是校验值，普通用户不用下载。包内自带 .NET 运行时、染色引擎所需的 Python 环境、Tesseract 文字识别与游戏命令行工具，无需另装。

程序没有代码签名。第一次运行时 Windows 可能显示“Windows 已保护你的电脑”，点“更多信息”再点“仍要运行”。

## 2. 启动与主界面

运行 `Moongate.exe` 后，后台服务会随窗口一起启动，第一次运行时自动创建数据；关闭窗口时后台服务一起退出。窗口开着时再次双击 `Moongate.exe` 只会把窗口提到前台。

- **左侧栏**：上方是抓包状态（含当前地图）、“游戏连接器”胶囊与游戏窗口卡片，下方是各功能入口：DPS检测、合奏、乐谱库、染色、背包、角色、交易所、生活、浮窗版面。默认窗口大小下全部入口一屏放下。
- **绑定游戏窗口**：点游戏窗口卡片，在弹出的列表里选择《瑪奇 Mobile》窗口。列表为空时先启动游戏再点“刷新”。设置页可开启“自动选择游戏窗口”。
- **抓包**：绑定游戏窗口后自动开始，默认同时在所有网卡上抓包，并一直保持运行；合奏、DPS 检测、背包共用这一份抓包。设置页可以关闭自动抓包，或指定只抓一张网卡。
- **游戏连接器**：胶囊显示连接器状态，点开可以启用或恢复原设置，见 [4.1](#41-游戏连接器)。
- **状态提示**：读不到的数据显示“未读取”“未知”或“不适用”，不会用 0 代替；暂不能用的按钮会停用，并在旁边写明原因。
- **说明问号**：各页与卡片的说明收在标题旁的问号里，鼠标悬停、Tab 聚焦或点按即可查看。
- **调整侧栏顺序**：按住侧栏的模块入口上下拖动即可改变顺序。

## 4. 功能

### 4.1 游戏连接器

游戏连接器使用《瑪奇 Mobile》自带的命令行工具读取与控制游戏，Moongate 包内附带该工具。角色、交易所、背包估价、生活的采集加工制作、乐谱库的游戏内演奏与游戏乐谱同步、合奏的换乐器与开奏需要它；没有连接时这些入口停用并写明原因，其他功能照常使用。

1. 正常退出游戏。游戏运行时不能启用、关闭或恢复原设置。
2. 点侧栏抓包状态下方的“游戏连接器”胶囊，或打开设置页的“游戏连接器”卡片，打开“启用”。
3. 第一次启用会弹出确认窗口，说明会修改台服客户端的设置文件、把命令行工具复制到台服游戏目录、可能带来账号风险以及如何恢复。点“我已了解，启用”后才会修改，之后再启用不再询问。
4. 从 Nexon Launcher 启动游戏并进入角色。胶囊显示“已连接”后即可使用。

| 胶囊状态 | 含义与做法 |
|---|---|
| 未启用 | 还没有启用连接器 |
| 游戏启动中 | 游戏刚启动、还没进入角色；进入角色后自动连接 |
| 已连接 | 可以使用 |
| 未连接游戏 | 已启用，游戏没有运行；从 Nexon Launcher 启动游戏并进入角色 |
| 已失效 | 游戏里的连接器设置已过期；正常退出游戏后重新启用，再从启动器启动游戏 |
| 检测中 | 正在检测，稍候自动刷新 |
| 不可用 | 卡片写明原因，例如命令行工具文件与已核对的版本不一致、找不到台服游戏目录 |

- **台服游戏目录**：卡片显示目录及其来源；找不到或不对时点“更改”，填写含 `MabinogiMobile.exe` 的文件夹后点“应用”。
- **恢复原设置**：正常退出游戏后点“恢复原设置”，连接器相关的客户端设置回到第一次启用之前，其他设置不变。复制到游戏目录的命令行工具保留在原处。
- 台服游戏目录里已有一个不同版本的同名命令行工具时，启用会被拒绝，原文件不会被覆盖。

### 4.2 DPS 检测

1. 确认左上角正在抓包，然后正常战斗。伤害自动计入当前这场与当前分段。
2. 标题行可以“拆段”（从现在起开始新分段）或“结束本场”。“自动观测”开关控制是否自动统计。
3. **统计范围**：整场、当前分段或定时测量。结果不完整时会显示原因。切换地图，或脱离战斗后 3 分钟没有战斗动作，这一场就结束：之后整场仍显示上一场（标题标“上一场”），下一次造成伤害时才开始新的一场。脱离战斗后 10 秒内又打起来，仍算同一个分段。
4. **选择目标**：“全部”或某个目标；选中目标时显示对它的伤害和你的贡献占比。目标太多时折叠为“+N”，点开展开。
5. **伤害面板**：总伤害、DPS、攻击特性（暴击、强击等比率列在 DPS 下方）、首击、元素构成与伤害归属；下方依次是治疗、自身效果与怪物效果、破防期间、按技能／按目标明细和战斗记录。
6. **定时测量**：点时长（默认 1:00）设定分、秒，再点“开始计时”。计时从首次伤害开始，结束后结果列在测量记录里。也可以在设置里给“开始／取消定时测量”分配快捷键。
7. **保存记录**：给当前结果命名保存；“重设”把整场、当前分段和定时测量一起清空，已保存的战斗记录不受影响。战斗记录每行的“明细”打开这条记录的明细窗口（主数据、治疗、破防、DPS 曲线、排行与总表，可按目标筛选、可导出），标题写记录名称与保存时间；最多同时打开 4 个，便于对比。旧版本保存、只有摘要的记录只显示 DPS、总伤害与时长。
8. **明细窗口**：明细表左上角“在窗口中打开”。窗口里的范围、目标切换只影响窗口本身；窗口里有治疗明细表，鼠标停在 DPS 曲线上会显示该点的时间和数值，整场曲线按电脑时钟标注时刻。
9. **治疗浮窗**：在浮窗版面页的元件库加入“治疗”，显示当前范围的 HPS、总治疗量、治疗次数与受到治疗的有效比例。
10. **效果收藏**：在效果卡片上点星标或“收藏…”。“收藏…”可以按名称（简繁都可）或编号搜索客户端里的全部 buff，没在游戏里出现过的也能收藏。打开“只显示收藏”后主页面、明细和效果浮窗都只列收藏的效果。

### 4.3 背包

1. 开着 Moongate 抓包时登录角色（已在游戏中的可以重新登录），游戏下发完整背包数据后自动同步。页面标题区写着同步状态与时间。
2. 顶部选择账号；“显示”开关选择要看的列组：角色保管箱、背包、公共保管箱，以及“估价”。
3. 透视表每行一种道具：名称、类别、合计、公共保管箱，以及每个角色的角色保管箱与背包。“未读取”表示这一处还没收到数据，0 只在确知没有时出现。乐谱每张一行，名称就是谱名，鼠标停在名称上可以看到作曲、编曲、能否复制、是否收藏与上锁。
4. **资源**卡是货币的集中位置，卡片用游戏图标显示各项货币。顶部选择角色（默认当前登录角色），其下是金币（免费 + 付费）、银币与魔族貢品，银币和贡品在名称下方显示下一次补充的倒计时，到点后标“待进图”（游戏在下次进图时结算）；补充上限没有会员时为 100／10，奇幻生活全方位会员生效时为 150／15，达到上限时写“已满”。上限在登录或换频道时判定，只有单项会员时不显示上限。再往下是账户资源（跟随账号）与角色资源（跟随所选角色）。启用游戏连接器时，当前登录角色的货币以连接器读数为准，其他角色和连接器读不到时用抓包数据；鼠标停在数值上可以看到来源。
5. **估价**：打开“显示”里的“估价”（需要游戏连接器）后，表格增加“估价（德卡）”列，按交易所最低单价乘以持有数量计算；读不到价格时写原因（例如无在售、不可交易），同步状态下方写明取价时间与已估价项的合计，含无法估价的项时标“下限”。打开后每 60 秒更新一次，只在背包页显示时取价；开关只在本次运行内记住。
6. 搜索框在名称、类别、备注与乐谱的作曲、编曲里查找。双击“备注”列或按 F2 编辑备注，备注按账号保存在工具文件夹里。
7. “导出 CSV”导出当前看到的列与行；“在窗口中打开”在独立窗口里查看同一张表。

### 4.4 角色

角色页需要游戏连接器（昵称取自抓包）。页面显示时才读取，标题行的“刷新”立即重读。

- **概况**：昵称、服务器、称号、等级、战斗职业，以及战斗力、生活力、魅力、装饰分数四项评分。
- **状态**：体力、护盾、饱腹、背包重量与生效 Buff 数。
- **属性**与**生活技能**（等级与经验）。
- **任务**：日常与周常两个页签，未完成的在前，“已完成，待领奖”单列。
- **成长指南**：未解锁的内容写明解锁条件。
- **周边**：区域、频道、天气、游戏内时间、位置与住宅。

每张卡片标题处写明来源与读取时刻（例如“游戏连接器 · 12:03:11”），沿用上次结果时标“旧数据”，读不到的项显示“未读取”。“编辑布局”可以调整卡片的顺序与大小。

### 4.5 交易所

交易所页需要游戏连接器，只查价，不能买卖。

1. 选择查价方式：名称（可输入多个，用空格、逗号或顿号分隔，每个至少 2 个字）、分类（分类与子分类）或收藏。
2. 结果按名称分组，列出道具名、品阶／星级／赛季（有则显示）、是否在售与最低单价（德卡），并标注取价时间。
3. 选中一行并输入数量，查询明细：最低与最高挂单价、平均成交价、最多三档挂单价与数量，以及按数量计算的购买成本；数量超过三档合计时只给已定价部分的小计并标“下限”。
4. 游戏要求等待时按钮停用并倒计时，到时再点；交易所暂不可用、道具不存在或有多项匹配时写明原因，多项匹配时可以点选候选再查。

### 4.6 生活

生活页由加工设施、制作、采集、专注钓鱼与总队列几张卡片组成，标题旁的“编辑布局”可以调整顺序与大小。采集、加工、制作需要游戏连接器；专注钓鱼不需要。

1. **加工设施**：每个设施一块，圆点依次表示已完成、加工中、已安排待执行与空槽（＋）。设施内的加工按顺序逐项进行，副标题写“当前剩余”与“全部完成”还需的时间，鼠标停在圆点上可以看到该项多久后完成。点已完成的圆点或“全部领取”领取该设施的全部成品（没有已完成项目时“全部领取”停用）；点空槽在配方菜单里选择配方与项数，加入总队列末尾。游戏没有提供设施等级与槽位总数，设施块画出已有的加工项目与一个空槽，游戏报告槽位已满时写“槽位已满”。
2. **制作**：按制作设施分块，点开后在配方菜单里看到成功率、大成功率、每次产出与材料持有／需要，填好次数加入总队列。制作执行尚未经实机确认，界面上有标注。
3. **采集**：按生活技能折叠，展开后填写目标数量（个，默认 10）加入总队列。命令行每次以 10 个为目标采集，实得可能更多，累计达到目标数量即完成。钓鱼类采集物请用专注钓鱼。
4. 配方菜单顶部可以按配方名或材料名搜索。
5. **总队列**：任务按顺序执行，可以拖动或用上移、下移排序，改数量或删除。页面顶部的控制条有“开始”（暂停后为“继续”）、“暂停”（当前这一次调用结束后停下）、“停止当前”（立即中断，游戏里这一次的结果按未知处理）与“清空已完成”。
6. **花费确认**：开始或继续前会列出每项的单次花费与次数、整队花费上限，并提醒会自动移动角色；采集、加工、制作每次消耗精靈之翼，领取不消耗。确认后才执行，可以勾选“本次运行期间不再询问”。
7. 任务遇到游戏拒绝、游戏里有界面挡住、精靈之翼或材料不足时，整个队列暂停，写明原因、停在哪一项和已完成多少，不跳过、不自动重试；处理后点“继续”从该项剩余的部分接着执行。
8. 加工完成时左上角状态会提示，不弹窗、不响铃。“到点自动领取”默认关闭，开启后只在本次运行内有效。
9. 关闭 Moongate 后队列保留，下次打开时处于暂停并写明“工具重启后暂停”，确认后手动继续。
10. **专注钓鱼**：
    - 条件：已绑定游戏窗口，窗口没有最小化，游戏画面区域为 1280×960。条件不满足时“开始钓鱼”停用并写明原因。
    - 先把角色停在可钓鱼的位置，设定时长（小时、分钟、秒；全部留空表示直到停止，填写时为 1 分钟到 24 小时），点“开始钓鱼”并确认。工具原地抛竿、收竿与续抛，不寻路；运行期间在后台向游戏窗口发送 W/S、空格按键与点按。
    - 运行中显示阶段、已用时长与目标时长、轮次统计。“收竿结束”离开钓鱼姿态后结束，“立即停止”马上停止。背包满时自动停止。
    - 专注钓鱼与总队列、合奏、演奏、染色不能同时进行。
11. 浮窗元件“加工设施”显示各设施的圆点与剩余时间，“生活队列”显示队列状态、当前任务与进度和下一项；元件解锁后可以领取、点空槽安排加工、暂停、继续或停止当前任务。

### 4.7 合奏

1. **连接房间**：填写昵称（默认用抓包识别到的角色名，也可切换为自定义昵称），选择联机方式：
   - 服务器直连：房主“创建公网房间”，成员输入六位房间码“加入房间”。
   - 局域网：同一路由器或已用组网软件互通的电脑之间使用，房主选择本机地址，成员填写房主地址与房间码。页面里有“连接教程”。
   - Cloudflare 公网需要另行配置 cloudflared 组件，包内未附带。
2. 房主建房后可“复制邀请”发给成员。
3. **成员表**：房主可以编辑每位成员的组号、顺序、身份（乐谱使用者／参与者）与乐器，按住行拖动调整，右键或行尾“···”指定总指挥或移出房间。
4. **本机动作**：开启“操作游戏”，设置开始方式与停止方式；需要点击游戏内按钮时用“点选按钮位置”在游戏窗口上点一下记录位置。
5. **开奏**：成员按“就绪”，房主按“开始”。倒计时结束时工具替每组的乐谱使用者点击乐谱“使用”或按开始键，参与者在游戏里按顺序加入合奏。
6. **停止**：房主可以取消本轮或全员停止；总指挥演奏结束时可以带动全员一起停止；成员可用“本机停止”。工具停止失败时会提示你在游戏中手动停止。
7. **游戏连接器**：启用并连接后，成员表里分配了乐器的成员按“就绪”时，工具先在游戏里换成该乐器再就绪；背包里没有该乐器或名称有歧义时无法就绪并写明原因。乐谱使用者的乐谱是游戏自带乐谱时，开奏经连接器发出，停止也经连接器执行；玩家自制乐谱仍按设置的开始方式（点击或按键）开奏。
8. 浮窗里的“信息浮窗”元件显示房间码、倒计时、成员与就绪状态，解锁后可直接点“开始”“就绪”。

### 4.8 染色

1. 打开游戏的染色界面，绑定游戏窗口。
2. 三张区域卡各设定：是否启用、优先级、目标色（输入 HEX、用选色浮层或吸管）、模式（精准 HEX，或相似颜色加 ΔE 容差）以及替代色（最多 63 个）。改动自动保存。
3. **吸管**：点吸管后工具切到游戏窗口，先截取光标所在的显示器并冻结画面，光标移到其他显示器时再截取那一块；在冻结画面上左键取色，右键或 Esc 取消。各显示器缩放比例不同时也能准确取到光标下的像素。
4. **选色方案**：保存当前设置为方案，或套用内置的“日系插画配色”“时尚设计配色”共十套预设。
5. 按“开始”寻色。开始前需要：已绑定游戏窗口且窗口没有最小化，程序文件夹里有完整的 `components\color-engine`（解压版自带）。条件不满足时“开始”停用，旁边写明缺的是哪一项。开始后工具把游戏窗口切到前台，截取游戏窗口画面识别色板并操作鼠标；寻色期间请保持游戏窗口在前台、不要移动或缩放窗口，切走或改变窗口会停止本次寻色。选“精准寻色”时工具还会只读游戏内存，客户端版本不受支持时会停止并写明原因。
6. 运行栏的状态行显示当前阶段与步骤，下面一行说明这一步在做什么、需要你做什么（例如“请进入染色界面”），并列出游戏实测色码与色差；还显示剩余时间与各区域判定。截图寻色完成一轮后显示“本轮寻色已完成”，可点“重试”在本局剩余时间内再找一次；有多个候选时可以选择。按“停止”或 **F9** 立即停止。
7. 寻色没有完成时，状态行写明结果（例如“游戏失去焦点，已停止寻色”“无法读取游戏进程（权限被拒绝）”“等待染色界面超时”），说明行给出原因与下一步；精准寻色准备失败时还写明停在哪一步。游戏以管理员身份运行时，精准寻色需要以管理员身份运行 Moongate。
8. 区域卡的“当前”“实测”是工具在游戏画面上读到的色码：寻色进行中显示最新一次读到的颜色、色差与判定，没读出的区域显示“未读取”；结束时没有再次核对游戏颜色的，“实测”一行标为“上次实测（当前未确认）”，这时请以游戏当前颜色为准。
9. 浮窗版面里的“当前颜色”元件在游戏上方显示同样的内容：当前阶段与指引、剩余时间、各区域实测色码与色差、结果与下一步，有候选时可以选择；解锁元件后可以点“停止”或“重试”，上锁时鼠标穿透到游戏。
10. 游戏和 Moongate 可以放在不同的显示器上，显示器缩放为 100%、125%、150% 都可以寻色。
11. **寻色记录**保留最近 30 次的结果。

### 4.9 乐谱库与迷你窗

1. **乐谱来源**：乐谱表合并三类来源，名称前的标签区分“游戏乐谱”（游戏自带的乐谱，经游戏连接器从游戏同步）、“自制乐谱”（从背包抓包读到的玩家自制与复制乐谱，不需要连接器）和“导入”（以前版本导入的乐谱），表头上方可以按来源筛选。打开页面、点“重新同步”以及页面显示期间每分钟同步一次。游戏里已经没有的乐谱标“游戏里已没有”，不能加入队列。
2. 乐谱表列出名称、编曲、时长与操作。选中行后按 Ctrl+C 或右键“复制乐谱名”只复制乐谱名，每行一个。
3. **清单**：每行的“加入清单”把乐谱加入某个清单。“管理清单”里可以新建清单与文件夹，给清单改名、写备注、指定默认乐器、移动或删除（删除要再点一次“确认删除”），调整清单里乐谱的顺序、移除或给单首指定乐器。
4. **演奏队列**：“加入队列”需要先绑定游戏窗口。队列每一项可以选择“游戏当前乐器”（不换乐器）或当前角色背包里的乐器（背包同步后列出，名称为游戏原文）；从清单加入时带上清单里指定的乐器。演奏进行中不能改乐器。
5. **游戏内演奏**：标题区的“游戏内演奏”打开操作层，有开始演奏、下一首、停止、当前曲目与状态，以及播放顺序、曲间等待等设置。开始前按每一项指定的乐器换乐器，再在游戏里演奏，并按队列连续播放。这些操作需要游戏连接器；玩家自制乐谱受游戏限制不能经连接器演奏，选中时“开始演奏”停用并说明。游戏拒绝演奏（例如战斗中、骑乘中、没有乐器）时写明原因。
6. **迷你窗**：标题区的“迷你窗”打开窄长的小窗，与主窗口同时使用，可以选清单、选乐谱加入队列，开始演奏、下一首、停止与紧急停止。
7. 乐谱库不再提供导入入口，以前导入的清单与乐谱照常显示。

### 4.10 浮窗

1. 打开“浮窗版面”页。元件库里每个元件右侧的开关决定它是否显示在浮窗上（DPS、技能、自身效果、怪物效果、收藏浮窗、觉醒监控、定时测量、治疗、合奏信息、当前演奏、当前颜色、加工设施、生活队列等）；点元件本身只是选中，在右侧调整缩放、外观（玻璃、纯色、自定图像）、背景与内容不透明度和配色。新打开的元件默认解锁，可以直接拖动。
2. **在屏幕上摆放**：按“屏幕上摆放”卡片的“编辑位置”，元件直接显示在各显示器上（包括已关闭的元件），拖动摆放、拖右下角改尺寸，完成后按屏幕顶部提示条或卡片上的“完成编辑”保存。
3. **换显示器**：所选元件详情里的“移到显示器”、卡片上的“全部移到”，或编辑时元件上的箭头按钮都可以把元件换到另一块显示器；“全部移回主显示器”与“恢复默认位置”用来找回看不见的元件。经远程桌面操作、无法直接跨屏拖动时用这些按钮。
4. 可以保存多套版面，点“显示浮窗”在游戏上方显示。浮窗每块显示器一个，置顶且不抢游戏焦点。
5. 浮窗上每个元件右上角有锁和关闭按钮：上锁后鼠标穿透到游戏，解锁后可以拖动、改尺寸与操作，悬停时还可以用“－／＋”调整缩放、用半圆按钮调整不透明度。**F8** 显示或隐藏浮窗，**F7** 全部上锁或解锁。
6. “环境信息”（频道、区域、天气与游戏内时间）与“附近演奏字幕”（附近玩家正在演奏的曲目，同一曲目只提示一次）放在“需要游戏数据的元件”里，需要游戏连接器；暂不可用时标注原因。
7. 可选“游戏最小化时隐藏”与“录屏时隐藏”。
8. **配色**：“配色”卡片调整整个浮窗的颜色（底板、文字、强调与状态、条形、效果条目、图标），每组可恢复原配色；选中某个元件后还可以单独设置它的底板与文字颜色。
9. **收藏浮窗**：“收藏浮窗 1”“收藏浮窗 2”只显示你收藏的 buff，不受“只显示收藏”影响。选中后在右侧勾选每个收藏要看“自身”还是“目标”（目标与 DPS 浮窗血量条是同一个当前目标）。没出现的 buff 变暗常驻；换地图后自身 buff 标“推算”继续倒计时；元件解锁时按住一项拖动排序。
10. **觉醒监控**：单独的“觉醒监控”元件显示第一季徽章觉醒：觉醒时亮起，显示徽章名与剩余时间并闪烁，结束后显示冷却倒计时。DPS 元件内也有同样的徽章觉醒显示，默认打开，可在 DPS 元件的设置里关闭。两处共用一组设置：闪烁颜色、时长与提示音（默认关闭，可用内置音或本机 wav／mp3），在任一处修改另一处同步。

### 4.11 模块与扩展

- **已安装模块**：查看各模块状态，启用或停用非核心模块。
- **素材包**：“导入素材包”选择一个含 `pack.json` 的文件夹，替换图标、背景与动效；移除即恢复内建外观。制作方法见[素材包制作](asset-packs.md)。
- **扩展模块**：“安装扩展模块”选择 `.zip`，先显示检查结果（标识、版本、发布者、文件数、大小、签名状态），确认后安装。带程序的扩展还会列出运行方式、申请的普通权限与高风险权限、访问的主机。安装的扩展默认停用，可随时启用、停用或卸载。也可以把 `.zip` 放进扩展文件夹的 `inbox` 里，在页面上逐个检查安装。
- **权限**：普通权限（读取数据、提供页面与浮窗元件等）在确认安装时授予；截图、联网、读取文件、操作游戏等高风险权限默认关闭，在扩展卡片上逐项按“授予”打开，随时可以“撤销”，撤销立即生效。
- **运行状态与日志**：带程序的扩展在独立进程里运行，卡片显示运行状态；出错时可以按“重启”，按“日志”查看最近的输出。扩展提供的页面在侧栏“扩展”分组里，浮窗元件在浮窗版面页的元件库里，设置项在设置页“扩展”卡片里。
- 扩展程序以当前 Windows 用户身份运行，请只安装信任来源的扩展。制作方法见[扩展模块开发](extensions.md)。

### 4.12 诊断

- **调试采集**：限时记录更详细的运行信息，开始前会说明收集范围。
- **导出排查包**：把诊断信息打包保存，用于提交问题。

## 6. 数据位置、升级与卸载

所有文件都在工具文件夹内：

| 位置 | 内容 |
|---|---|
| `Moongate.exe` | 启动入口 |
| `components` | 程序本体与随包运行环境 |
| `licenses` | 第三方声明（`THIRD_PARTY_NOTICES.txt`，含本项目 MIT 许可）与组件清单 `sbom.spdx.json` |
| `userdata\data` | 数据库、设置、日志、诊断、备份、扩展模块（第一次运行后出现，下同） |
| `userdata\desktop` | 界面偏好、浮窗版面、背包备注、效果收藏、素材包 |
| `userdata\bootstrap`、`userdata\runtime` | 启动配置与运行中的实例信息 |

**应用内更新。** 设置页“更新”卡片显示当前版本、发现的新版本、本次是“增量更新”还是“完整下载”及下载大小、下载进度、上次检查时间和上次安装结果。开启自动检查时，每次打开 Moongate 约 10 秒后检查一次，之后按设置的间隔检查；还没检查过时状态写“尚未检查”，发现新版本时窗口右上角出现“有新版本”提示。增量更新只从完整包里取本机缺少或有变化的文件，隔了几个版本也一样；要换的文件接近整个程序或网络不支持分段下载时自动改为下载完整包，显示实际大小；增量失败时同时说明原因，重新检查或复用下载内容后也保留；没有新版本时状态写“已是最新版本”，连不上 GitHub 时写明原因。发现新版本后点“下载更新”，会先弹出确认窗口，显示新版本、下载方式与大小和这个版本的更新说明（只显示当前界面语言的那一份），点“下载”才开始下载，点“取消”、窗口外或按 Esc 都不下载；下载并校验完成后点“安装并重启”：正在演奏、染色、定时测量或在房间里时会先等这些活动结束；随后 Moongate 关闭，替换程序文件后自动打开新版本。新版本没能正常启动时会自动回到原来的版本并恢复数据，设置页写明原因。工具只从本项目的 GitHub Releases 下载（不依赖 GitHub API，连不上时才改用），核对 SHA-256 与每个文件的内容后才安装，不会降级。

**从 0.1.6 或更早版本升级到本版。** 请按下面的手动升级步骤操作；0.1.7、0.1.8 可以直接在应用内更新。

**手动升级。** 把新版本的压缩包解压到一个新文件夹，关闭 Moongate，把旧文件夹里的 `userdata` 整个移到新文件夹里（与新的 `Moongate.exe` 放在一起），再运行新的 `Moongate.exe`；确认正常后删除旧文件夹。也可以在关闭 Moongate 后，用新包里的 `components`、`licenses` 与 `Moongate.exe` 替换旧文件夹里的同名三项。自动更新失败且旧版本也无法打开时，工具会弹出同样的步骤。

卸载时先关闭 Moongate 窗口，再删除整个文件夹即可。

## 7. 常见问题

**抓包状态写“未安装 Npcap”。** 安装 Npcap 后无需重启，工具每隔 5–60 秒自动重试，约一分钟内开始抓包；也可以在设置里把自动抓包关闭再打开立即重试。

**装了 Npcap 仍然抓不到数据。** 网卡选“自动”时，工具同时在所有网卡上抓包（包括加速器的隧道网卡和 Npcap 的回环适配器），只收游戏程序自己的连接，并按游戏数据的特征认出真正的游戏连接，不需要选网卡；状态里的“来源”写明数据来自哪类网卡，例如“回环（加速器）”。抓包中约 20 秒仍显示“收不到游戏数据”时：先确认安装 Npcap 时勾选了“Support loopback traffic”（回环支持，默认勾选；没勾选时重新运行安装程序勾上），多数本机代理型加速器的游戏数据只在回环上；仍不行时到设置页的抓包部分点“列出网卡”，或用“开始检测”找出有游戏数据的网卡后确认使用该网卡。显示“等待角色信息，请切换一次地图”时，在游戏里切换一次地图或频道即可。

**加载地图或地下城重试时 DPS 中断。** 游戏加载期间窗口短暂无响应或重建窗口时，工具保持对同一游戏的绑定和抓包，加载结束后 DPS 继续统计；加载期间合奏、染色等需要操作游戏窗口的功能暂停，窗口恢复后可继续。抓包因故重新开始时，工具沿用此前识别的本机角色；如果显示“等待角色信息，请切换一次地图”或“角色待确认，请切换一次地图”（沿用的角色在新地图里没有得到确认，这时 DPS 不统计，避免算错），切换一次地图即可。野外人多、游戏连接频繁变化时偶尔漏掉一小段数据，DPS 分段照常继续，只标为数据不完整。

**状态写“指定的网卡不存在，已改为自动”。** 设置里指定的网卡已拔出、改名或换了电脑，工具改为在所有网卡上抓包，抓包照常进行；到设置页重新指定网卡或改回“自动”后，这句提示消失。

**游戏更新后。** 工具会读取本机的新版游戏文件自动核对，核对期间显示“正在核对新版游戏”，通过后照常抓包，状态写“已适配新版游戏”。新版只调整了数据编号、结构没变时，工具按名称自动对应，功能照常。某项功能的数据格式在新版里有变化时，只停用这一项并写明（例如“新版游戏：战斗统计暂停用”），其他功能照常；等工具更新后恢复。

**合奏页没识别出我的角色。** 确认正在抓包后，在游戏里切换一次地图。

**背包一直显示“未读取”。** 背包数据在角色登录时下发。开着 Moongate 抓包时重新登录角色。

**游戏连接器显示“未连接游戏”“游戏启动中”或“已失效”。** 启用后需要从 Nexon Launcher 重新启动游戏并进入角色；游戏刚启动、还没进入角色时显示“游戏启动中”，进入角色后自动连接。显示“已失效”时，正常退出游戏，在胶囊里重新启用，再从启动器启动游戏。

**启用游戏连接器时提示游戏正在运行。** 启用、关闭与恢复原设置都要先正常退出游戏。

**角色页、交易所或生活页的按钮是灰的。** 这些功能需要游戏连接器，按钮旁写明原因（例如“游戏连接器未启用”），按 [4.1](#41-游戏连接器) 启用并连接后自动放开。

**乐谱的“开始演奏”是灰的。** 选中的是玩家自制乐谱时，游戏不允许经连接器演奏；游戏连接器没有连接时，“游戏内演奏”层顶部写明原因。

**生活队列暂停了。** 页面顶部的横幅写明原因、停在哪一项和已完成多少。按提示在游戏里处理（例如关闭挡住的界面、补充精靈之翼或材料）后点“继续”；工具重启后的暂停确认后直接继续。

**专注钓鱼不能开始。** 看“开始钓鱼”旁写的原因：需要先绑定游戏窗口，窗口不能最小化，游戏画面区域需要正好 1280×960；总队列、合奏、演奏或染色进行中时也不能开始。

**启动时提示无法写入。** 工具文件夹没有写入权限。把整个文件夹移到 `D:\Moongate` 这类普通位置。

**双击后没有窗口，或提示后台启动失败。** 后台没能启动时，底部“未连接后端”处会写明原因和做法：程序放在 Program Files 等受保护目录、桌面或文档被 Windows“受控文件夹访问”拦截、网络位置、同步盘目录、写保护的 U 盘，或数据属于其他 Windows 用户。按提示把整个 Moongate 文件夹移到 `D:\Moongate` 之类的普通文件夹，或在“Windows 安全中心 → 病毒和威胁防护 → 勒索软件防护 → 允许应用通过受控文件夹访问”中添加 `components\dotnet-runtime\dotnet.exe` 与 `components\desktop\MabiTool.Desktop.exe`。需要反馈时到诊断页按“导出启动记录”保存一个文本文件（用户名已替换）发给开发者。从压缩包查看器里直接运行时工具会提示先完整解压。第一次启动若中途失败或被打断（例如被安全软件结束、断电），旧版本之后会一直提示“初始化须使用空目录”；新版本会接着完成初始化，升级后直接打开即可，不需要删除 `userdata`。只有 `userdata\data` 里放进了不属于 Moongate 的文件时才会拒绝，并写明是哪一个文件。

**底部显示“未连接后端”。** 底部状态与设置页“后端”卡片的“连接”一行写有原因。写着“本机端口 19998 已被占用”时，是另一个文件夹里的 Moongate 仍在运行（解压了两份，或旧的一份没退出就打开了新的一份）：关闭那一份的 Moongate 窗口，或在任务管理器的“详细信息”里结束命令行含 MabiTool.Host 的 dotnet.exe，然后重新打开。19998 被其他软件占用或被系统保留时 Moongate 会自动改用空闲端口，不需要处理，设置页“后端”卡片的“地址”一行显示实际端口。其他原因按提示处理；需要反馈时在诊断页导出启动记录。

**怎样完全退出。** 关闭 Moongate 窗口即可：后台服务随窗口一起退出，正在进行的合奏演奏、染色与定时测量会停止并释放游戏操作，生活队列保留到下次打开时处于暂停，不留后台进程。窗口开着时再次双击 `Moongate.exe` 只会把窗口提到前台。后台服务意外停止时底部状态写“后端已停止”，Moongate 会自动重新启动它一次；再次停止时请关闭并重新打开 Moongate。

**工具点不动游戏，或绑定时提示“游戏以管理员身份运行”。** 游戏以管理员身份运行时，Windows 不允许普通权限的程序操作它，Moongate 不会绑定这样的窗口。关闭 Moongate 后右键 `Moongate.exe` 选“以管理员身份运行”，或改为以普通身份启动游戏。

**合奏用局域网建房，别人连不上。** 第一次建房时 Windows 防火墙会询问是否允许 `dotnet.exe`（Moongate 的后台服务）访问网络，请勾选“专用网络”并允许。加入方提示“连不上房主，请检查防火墙”时，请房主在“Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙”里给 `dotnet.exe` 勾上“专用”，并在“设置 → 网络和 Internet”里把当前网络设为“专用网络”（“公用网络”下局域网连接会被拦截）。邀请里列出多个地址时，优先用与对方同一网段的那个。

**屏幕较小或开了 125%／150% 缩放。** 主窗口启动时会按屏幕可用区域自动缩小，标题栏始终在屏幕内；页面内容可以上下滚动。

**游戏装在其他磁盘并用联接挂回原路径。** 可以正常使用，工具会按实际位置核对游戏文件。

**电脑开了系统代理或加速器的代理模式。** 不影响 Moongate 窗口与后台服务之间的连接；检查更新访问 GitHub 时沿用系统代理。

**系统版本过旧。** 低于 Windows 10 1703 时双击 `Moongate.exe` 会提示升级系统。

**精准寻色没有开始操作就停止了。** 按运行栏的提示处理：
- “色卡被其他窗口遮挡”：把挡在染色画面上的窗口（聊天、录屏、通知等）移开后重新开始。寻色期间盖在游戏画面上的 Moongate 窗口（主窗口、浮窗、明细窗）会自动不进入截图（Windows 10 2004 及更新），不用手动隐藏；这些窗口这时也不会出现在录屏和远程桌面画面里，把它移开游戏画面即可恢复显示。没有盖住游戏的窗口照常显示。
- “色码识别超时”：电脑较忙时文字识别来不及完成。关闭占用大的程序后重试，也可以改用截图寻色。
- “色码核对不一致”“色块颜色有偏差”：关闭显卡或显示器的画面滤镜、夜间模式、HDR 与色彩增强后重试。
- “画面分辨率无法对应”：游戏用了低于显示器的全屏分辨率或分辨率缩放。请改为窗口化，或把游戏分辨率设为与显示器一致。
- “显示缩放导致画面尺寸不一致”：还原游戏窗口后重新开始；仍出现时把 Moongate 与游戏放在同一显示器上。
- “游戏引擎已更新”：这一版 Moongate 还不认识新的游戏引擎，精准寻色暂不可用，请改用截图寻色，等待工具更新。
- “文字识别读不到路径”：Moongate 文件夹的路径里有系统编码不支持的字，把整个文件夹移到 `D:\Moongate` 这类纯英文路径。
- “缺少 Windows 媒体功能包”：Windows N／KN 版本需要先在“设置 → 应用 → 可选功能 → 添加功能”中安装“媒体功能包”，重启电脑后再打开 Moongate。

**浮窗挡住了游戏操作。** 按 F7 把全部元件上锁，鼠标即可穿透到游戏；或按 F8 隐藏浮窗。

**想反馈问题。** 在“诊断”页导出排查包，连同复现步骤提交到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。
