# Moongate 使用说明

[简体中文](user-guide.md) · [繁體中文](user-guide.zh-TW.md) · [返回首页](../README.md)

本说明对应 Moongate 0.1.0（测试版）。这一版的功能清单与已知问题见[更新说明](release-notes-0.1.0.md)。

## 1. 准备

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 64 位 |
| 游戏 | 《瑪奇 Mobile》台服 Windows 客户端 |
| Npcap | 抓包必需，需自行安装：[npcap.com](https://npcap.com/#download)。安装时保持默认选项即可 |
| 放置位置 | 你有写入权限的普通文件夹，例如 `D:\Moongate`；不要放在 `C:\Program Files`、OneDrive 同步目录或网络磁盘 |

在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的最新版本下方 Assets 里下载排在最上面的 `Moongate-v0.1.0-Windows-x64.zip`（约 170 MB，解压后约 430 MB），完整解压后运行 `Moongate.exe`。同一发行里的 `.sha256` 是校验值，普通用户不用下载。包内自带 .NET 运行时、染色引擎所需的 Python 环境与 Tesseract 文字识别，无需另装。

程序没有代码签名。第一次运行时 Windows 可能显示“Windows 已保护你的电脑”，点“更多信息”再点“仍要运行”。

## 2. 启动与主界面

运行 `Moongate.exe` 后，后台服务会随窗口一起启动，第一次运行时自动创建数据；关闭窗口时后台服务一起退出。窗口开着时再次双击 `Moongate.exe` 只会把窗口提到前台。

- **左侧栏**：上方是游戏窗口卡片与抓包状态（含当前地图），下方是各功能入口。核心功能尚未完成的模块收在“未实现模块”分组里。
- **绑定游戏窗口**：点游戏窗口卡片，在弹出的列表里选择《瑪奇 Mobile》窗口。列表为空时先启动游戏再点“刷新”。设置页可开启“自动选择游戏窗口”。
- **抓包**：绑定游戏窗口并确定网卡后自动开始，并一直保持运行；合奏、DPS 检测、背包共用这一份抓包。设置页可以关闭自动抓包、查看或更换网卡。
- **状态提示**：读不到的数据显示“未读取”“未知”或“不适用”，不会用 0 代替；暂不能用的按钮会停用，并在旁边写明原因。
- **说明问号**：各页与卡片的说明收在标题旁的问号里，鼠标悬停、Tab 聚焦或点按即可查看。
- **调整侧栏顺序**：按住侧栏的模块入口上下拖动即可改变顺序。

## 3. 设置

| 设置项 | 说明 |
|---|---|
| 语言 | 简体中文 / 繁體中文 |
| 主题与动效 | 浅色 / 深色，动效可关闭 |

## 4. 功能

### 4.1 DPS 检测

1. 确认左上角正在抓包，然后正常战斗。伤害自动计入当前这场与当前分段。
2. 标题行可以“拆段”（从现在起开始新分段）或“结束本场”。“自动观测”开关控制是否自动统计。
3. **统计范围**：整场、当前分段或定时测量。结果不完整时会显示原因。切换地图，或脱离战斗后 3 分钟没有战斗动作，这一场就结束：之后整场仍显示上一场（标题标“上一场”），下一次造成伤害时才开始新的一场。脱离战斗后 10 秒内又打起来，仍算同一个分段。
4. **选择目标**：“全部”或某个目标；选中目标时显示对它的伤害和你的贡献占比。目标太多时折叠为“+N”，点开展开。
5. **伤害面板**：总伤害、DPS、攻击特性（暴击、强击等比率列在 DPS 下方）、首击、元素构成与伤害归属；下方依次是治疗、自身效果与怪物效果、破防期间、按技能／按目标明细和战斗记录。
6. **定时测量**：点时长（默认 1:00）设定分、秒，再点“开始计时”。计时从首次伤害开始，结束后结果列在测量记录里。也可以在设置里给“开始／取消定时测量”分配快捷键。
7. **保存记录**：给当前结果命名保存；“重设”把整场、当前分段和定时测量一起清空，已保存的战斗记录不受影响。
8. **明细窗口**：明细表左上角“在窗口中打开”。窗口里的范围、目标切换只影响窗口本身；窗口里有治疗明细表，鼠标停在 DPS 曲线上会显示该点的时间和数值，整场曲线按电脑时钟标注时刻。
9. **治疗浮窗**：在浮窗版面页的元件库加入“治疗”，显示当前范围的 HPS、总治疗量、治疗次数与受到治疗的有效比例。
10. **效果收藏**：在效果卡片上点星标或“收藏…”，打开“只显示收藏”后主页面和浮窗都只列收藏的效果。

### 4.2 背包

1. 开着 Moongate 抓包时登录角色（已在游戏中的可以重新登录），游戏下发完整背包数据后自动同步。页面标题区写着同步状态与时间。
2. 顶部选择账号；“显示”开关选择要看的列组：角色保管箱、背包、公共保管箱。
3. 透视表每行一种道具：名称、类别、合计、公共保管箱，以及每个角色的角色保管箱与背包。“未读取”表示这一处还没收到数据，0 只在确知没有时出现。乐谱每张一行，名称就是谱名，鼠标停在名称上可以看到作曲、编曲、能否复制、是否收藏与上锁。
4. **概况**卡片显示角色、道具种数、金币（免费 + 付费）、银币与魔族貢品，银币和贡品显示下一次补充的倒计时。**资源**区分账户资源（跟随账号）与角色资源（可切换角色）。
5. 搜索框在名称、类别、备注与乐谱的作曲、编曲里查找。双击“备注”列或按 F2 编辑备注，备注按账号保存在工具文件夹里。
6. “导出 CSV”导出当前看到的列与行；“在窗口中打开”在独立窗口里查看同一张表。

### 4.3 合奏

1. **连接房间**：填写昵称（默认用抓包识别到的角色名，也可切换为自定义昵称），选择联机方式：
   - 服务器直连：房主“创建公网房间”，成员输入六位房间码“加入房间”。
   - 局域网：同一路由器或已用组网软件互通的电脑之间使用，房主选择本机地址，成员填写房主地址与房间码。页面里有“连接教程”。
   - Cloudflare 公网需要另行配置 cloudflared 组件，包内未附带。
2. 房主建房后可“复制邀请”发给成员。
3. **成员表**：房主可以编辑每位成员的组号、顺序、身份（乐谱使用者／参与者）与乐器，按住行拖动调整，右键或行尾“···”指定总指挥或移出房间。
4. **本机动作**：开启“操作游戏”，设置开始方式与停止方式；需要点击游戏内按钮时用“点选按钮位置”在游戏窗口上点一下记录位置。
5. **开奏**：成员按“就绪”，房主按“开始”。倒计时结束时工具替每组的乐谱使用者点击乐谱“使用”或按开始键，参与者在游戏里按顺序加入合奏。
6. **停止**：房主可以取消本轮或全员停止；总指挥演奏结束时可以带动全员一起停止；成员可用“本机停止”。工具停止失败时会提示你在游戏中手动停止。
7. 浮窗里的“信息浮窗”元件显示房间码、倒计时、成员与就绪状态，解锁后可直接点“开始”“就绪”。

### 4.4 染色

1. 打开游戏的染色界面，绑定游戏窗口。
2. 三张区域卡各设定：是否启用、优先级、目标色（输入 HEX、用选色浮层或吸管）、模式（精准 HEX，或相似颜色加 ΔE 容差）以及替代色（最多 63 个）。改动自动保存。
3. **吸管**：点吸管后工具切到游戏窗口并截取整个屏幕，在冻结画面上左键取色，右键或 Esc 取消。
4. **选色方案**：保存当前设置为方案，或套用内置的“日系插画配色”“时尚设计配色”共十套预设。
5. 按“开始”寻色。开始前需要：已绑定游戏窗口且窗口没有最小化，程序文件夹里有完整的 `components\color-engine`（解压版自带）。条件不满足时“开始”停用，旁边写明缺的是哪一项。开始后工具把游戏窗口切到前台，截取游戏窗口画面识别色板并操作鼠标；寻色期间请保持游戏窗口在前台、不要移动或缩放窗口，切走或改变窗口会停止本次寻色。选“精准寻色”时工具还会只读游戏内存，客户端版本不受支持时会停止并写明原因。
6. 运行栏的状态行显示当前阶段与步骤，下面一行说明这一步在做什么、需要你做什么（例如“请进入染色界面”），并列出游戏实测色码与色差；还显示剩余时间与各区域判定。截图寻色完成一轮后显示“本轮寻色已完成”，可点“重试”在本局剩余时间内再找一次；有多个候选时可以选择。按“停止”或 **F9** 立即停止。
7. 寻色没有完成时，状态行写明结果（例如“游戏失去焦点，已停止寻色”“无法读取游戏进程（权限被拒绝）”“等待染色界面超时”），说明行给出原因与下一步；精准寻色准备失败时还写明停在哪一步。游戏以管理员身份运行时，精准寻色需要以管理员身份运行 Moongate。
8. 区域卡的“当前”“实测”是工具在游戏画面上读到的色码：寻色进行中显示最新一次读到的颜色、色差与判定，没读出的区域显示“未读取”；结束时没有再次核对游戏颜色的，“实测”一行标为“上次实测（当前未确认）”，这时请以游戏当前颜色为准。
9. 浮窗版面里的“当前颜色”元件在游戏上方显示同样的内容：当前阶段与指引、剩余时间、各区域实测色码与色差、结果与下一步，有候选时可以选择；解锁元件后可以点“停止”或“重试”，上锁时鼠标穿透到游戏。
10. 游戏和 Moongate 可以放在不同的显示器上，显示器缩放为 100%、125%、150% 都可以寻色。
11. **寻色记录**保留最近 30 次的结果。

### 4.5 乐谱库与迷你窗

乐谱库可以浏览乐谱、整理清单与演奏队列，并打开迷你窗。台服目前读不到游戏内的乐谱内容，游戏内自动演奏（选曲、换装、开始演奏、下一首）暂不支持，相关按钮停用并写明原因。

### 4.6 浮窗

1. 打开“浮窗版面”页，在元件库里点一下元件加入当前版面（DPS、技能、比率、自身效果、怪物效果、定时测量、治疗、合奏信息、当前颜色等），在右侧调整缩放、外观（玻璃、纯色、自定图像）与不透明度。
2. **在屏幕上摆放**：按“屏幕上摆放”卡片的“编辑位置”，元件直接显示在各显示器上（包括已关闭的元件），拖动摆放、拖右下角改尺寸，完成后按屏幕顶部提示条或卡片上的“完成编辑”保存。
3. **换显示器**：所选元件详情里的“移到显示器”、卡片上的“全部移到”，或编辑时元件上的箭头按钮都可以把元件换到另一块显示器；“全部移回主显示器”与“恢复默认位置”用来找回看不见的元件。经远程桌面操作、无法直接跨屏拖动时用这些按钮。
4. 可以保存多套版面，点“显示浮窗”在游戏上方显示。浮窗每块显示器一个，置顶且不抢游戏焦点。
5. 浮窗上每个元件右上角有锁和关闭按钮：上锁后鼠标穿透到游戏，解锁后可以拖动、改尺寸与操作，悬停时还可以用“－／＋”调整缩放、用半圆按钮调整不透明度。**F8** 显示或隐藏浮窗，**F7** 全部上锁或解锁。
6. 需要游戏数据而暂不可用的元件放在“需要游戏数据的元件”里，并标注原因。
7. 可选“游戏最小化时隐藏”与“录屏时隐藏”。

### 4.7 模块与扩展

- **已安装模块**：查看各模块状态，启用或停用非核心模块。
- **素材包**：“导入素材包”选择一个含 `pack.json` 的文件夹，替换图标、背景与动效；移除即恢复内建外观。制作方法见[素材包制作](asset-packs.md)。
- **扩展模块**：“安装扩展模块”选择 `.zip`，先显示检查结果（标识、版本、发布者、文件数、大小、签名状态），确认后安装。带程序的扩展还会列出运行方式、申请的普通权限与高风险权限、访问的主机。安装的扩展默认停用，可随时启用、停用或卸载。也可以把 `.zip` 放进扩展文件夹的 `inbox` 里，在页面上逐个检查安装。
- **权限**：普通权限（读取数据、提供页面与浮窗元件等）在确认安装时授予；截图、联网、读取文件、操作游戏等高风险权限默认关闭，在扩展卡片上逐项按“授予”打开，随时可以“撤销”，撤销立即生效。
- **运行状态与日志**：带程序的扩展在独立进程里运行，卡片显示运行状态；出错时可以按“重启”，按“日志”查看最近的输出。扩展提供的页面在侧栏“扩展”分组里，浮窗元件在浮窗版面页的元件库里，设置项在设置页“扩展”卡片里。
- 扩展程序以当前 Windows 用户身份运行，请只安装信任来源的扩展。制作方法见[扩展模块开发](extensions.md)。

### 4.8 诊断

- **运行状态**：后台各部分的状态，可“复制全部”。
- **最近记录**：按模块与级别筛选。
- **调试采集**：限时记录更详细的运行信息，开始前会说明收集范围。
- **导出排查包**：把诊断信息打包保存，用于提交问题。

## 5. 快捷键

| 快捷键 | 作用 |
|---|---|
| F9 | 紧急停止工具发出的游戏输入（合奏、染色） |
| F8 | 显示或隐藏浮窗 |
| F7 | 浮窗元件全部上锁或解锁 |

快捷键在设置页修改，按下录入框后按新组合，Esc 取消。

## 6. 数据位置、升级与卸载

所有文件都在工具文件夹内：

| 位置 | 内容 |
|---|---|
| `Moongate.exe` | 启动入口 |
| `components` | 程序本体与随包运行环境 |
| `licenses` | 第三方声明（`THIRD_PARTY_NOTICES.txt`，含本项目 MIT 许可）与组件清单 `sbom.spdx.json` |
| `userdata\data` | 数据库、设置、日志、诊断、备份、扩展模块（第一次运行后出现，下同） |
| `userdata\desktop` | 界面偏好、浮窗版面、背包备注、效果收藏、素材包 |
| `userdata\bootstrap`、`userdata\runtime` | 启动配置与运行中的实例信息 |

**应用内更新。** 设置页“更新”卡片显示当前版本、发现的新版本与大小、下载进度和上次安装结果。发现新版本后点“下载更新”，下载并校验完成后点“安装并重启”：正在演奏、染色、定时测量或在房间里时会先等这些活动结束；随后 Moongate 关闭，替换程序文件后自动打开新版本。新版本没能正常启动时会自动回到原来的版本并恢复数据，设置页写明原因。工具只从本项目的 GitHub Releases 下载，核对 SHA-256 与压缩包内容后才安装，不会降级。

**手动升级。** 把新版本的压缩包解压到一个新文件夹，关闭 Moongate，把旧文件夹里的 `userdata` 整个移到新文件夹里（与新的 `Moongate.exe` 放在一起），再运行新的 `Moongate.exe`；确认正常后删除旧文件夹。也可以在关闭 Moongate 后，用新包里的 `components`、`licenses` 与 `Moongate.exe` 替换旧文件夹里的同名三项。自动更新失败且旧版本也无法打开时，工具会弹出同样的步骤。

卸载时先关闭 Moongate 窗口，再删除整个文件夹即可。

## 7. 常见问题

**抓包状态写“未安装 Npcap”。** 安装 Npcap 后无需重启，工具每隔 5–60 秒自动重试，约一分钟内开始抓包；也可以在设置里把自动抓包关闭再打开立即重试。

**装了 Npcap 仍然抓不到数据。** 使用 VPN、加速器或多张网卡时，到设置页的抓包部分重新检测网卡，或手动选择游戏使用的网卡。

**合奏页没识别出我的角色。** 确认正在抓包后，在游戏里切换一次地图。

**背包一直显示“未读取”。** 背包数据在角色登录时下发。开着 Moongate 抓包时重新登录角色。

**启动时提示无法写入。** 工具文件夹没有写入权限。把整个文件夹移到 `D:\Moongate` 这类普通位置。

**双击后没有窗口，或提示后台启动失败。** 在工具文件夹打开终端运行 `components\core\launch-backend.cmd -Wait`，窗口会显示后台的启动输出与失败原因。从压缩包查看器里直接运行时工具会提示先完整解压。

**底部显示“未连接后端”。** 底部状态与设置页“后端”卡片的“连接”一行写有原因。写着“本机端口 19998 已被占用”时，是另一个文件夹里的 Moongate 仍在运行（解压了两份，或旧的一份没退出就打开了新的一份）：关闭那一份的 Moongate 窗口，或在任务管理器的“详细信息”里结束命令行含 MabiTool.Host 的 dotnet.exe，然后重新打开。19998 被其他软件占用或被系统保留时 Moongate 会自动改用空闲端口，不需要处理，设置页“后端”卡片的“地址”一行显示实际端口。其他原因按提示处理，或运行上一条的 `launch-backend.cmd -Wait` 查看。

**怎样完全退出。** 关闭 Moongate 窗口即可：后台服务随窗口一起退出，正在进行的合奏演奏、染色与定时测量会停止并释放游戏操作，不留后台进程。窗口开着时再次双击 `Moongate.exe` 只会把窗口提到前台。后台服务意外停止时底部状态写“后端已停止”，Moongate 会自动重新启动它一次；再次停止时请关闭并重新打开 Moongate。

**工具点不动游戏。** 游戏以管理员身份运行时，Moongate 也需要以管理员身份运行。

**浮窗挡住了游戏操作。** 按 F7 把全部元件上锁，鼠标即可穿透到游戏；或按 F8 隐藏浮窗。

**想反馈问题。** 在“诊断”页导出排查包，连同复现步骤提交到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。
