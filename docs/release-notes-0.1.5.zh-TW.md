> **測試版提示**
>
> Moongate 仍屬於測試版：各項功能已經可以使用，但可能還有問題。遇到問題或有建議，歡迎到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues) 回報。

**這一版的重點：** 修復戰鬥資料中斷與不完整（地下城重試進圖後沒有資料、野外首領戰資料缺失）；DPS 浮窗新增怪物血量，首領血量也能顯示；戰鬥記錄可以開啟明細；佔用的記憶體和 CPU 明顯降低；戰鬥屬性改用遊戲內建的圖示。

**下載哪個檔案：** 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的 v0.1.5 發行下方 Assets 裡，下載排在最上面的 **`Moongate-v0.1.5-Windows-x64.zip`**（約 170 MB，解壓縮後約 430 MB）。完整解壓縮到一個一般資料夾（例如 `D:\Moongate`），按兩下裡面的 **`Moongate.exe`** 即可執行。

**從舊版本升級：** 在設定頁「更新」裡「檢查更新」後「安裝並重新啟動」。0.1.4 只下載有變化的檔案；0.1.3 及更早的版本是完整下載。也可以手動升級：下載上面的正式包解壓縮，把裡面的檔案覆蓋到原來的 Moongate 資料夾（保留 `userdata`），再執行 `Moongate.exe`。

| 檔案 | 用途 |
|---|---|
| `Moongate-v0.1.5-Windows-x64.zip` | 正式包，下載這一個即可 |
| `Moongate-v0.1.5-Windows-x64.zip.manifest.json` | 應用程式內更新使用的檔案清單，不用下載 |
| `Moongate-v0.1.5-Windows-x64.zip.sha256` | 正式包的 SHA-256 校驗值，用來核對下載是否完整，一般使用者不用下載 |
| Source code (zip / tar.gz) | GitHub 自動附上的原始碼，一般使用者不用下載 |

## 這一版的變化

### 戰鬥統計

- **地下城重試進圖後不再沒有資料**：遊戲在載入時重建視窗，以前會被當成換了一個遊戲，抓包隨之中斷，要到下次換圖才恢復。現在只要遊戲處理程序還在就持續抓包。
- **野外首領戰資料不再缺失**：人多、連線頻繁變化時，以前會不斷遺失一小段資料，每遺失一次戰鬥分段就結束一次。遺失資料的原因已修復；即使偶爾缺了一小段，分段也不再結束，只在該分段和記錄上標註「資料不完整」。
- **怪物血量**：DPS 浮窗和 DPS 檢測頁顯示目前攻擊目標的名稱、血量條、目前值／最大值和百分比，首領的血量同樣可以顯示。顯示哪隻怪由你在遊戲裡選中的目標和最近的攻擊決定。在首領出現之後才開啟工具的情況下，血量會顯示「未讀取」，重新進入首領視野後恢復。
- **戰鬥記錄可以開啟明細**：記錄清單每一列新增「明細」，開啟與即時明細相同的視窗（技能、目標、各項比率、元素、治療、DPS 曲線），可以同時開啟四筆記錄對比。
- **「未知」怪物減少**：抓包中途重新開始後仍記得已經見過的怪物；名稱晚一步讀到時會補上；NPC、寵物、召喚物等現在也顯示名稱。用戶端裡本身沒有名字的怪物顯示「用戶端名稱為空」。
- **戰鬥屬性改用遊戲內建圖示**：暴擊、強擊、連擊、追擊、無防備、破防、多重打擊和八種元素在 DPS 頁、明細視窗和浮窗上顯示為圖示，停留可看名稱。圖示從你電腦上的遊戲用戶端讀取，讀不到時顯示文字。
- 抓包重新開始後，如果還在原來那張地圖，會沿用已識別的角色；換了地圖則提示「角色待確認，請切換一次地圖」。

### 效能

- 抓包元件處理同樣的資料，CPU 降到原來的約六成，記憶體配置減半；沒有遊戲資料時幾乎不佔用 CPU。
- 後端在戰鬥中停手、切到城鎮等閒置狀態下的 CPU 和寫入大幅減少；啟動時讀取遊戲檔案的記憶體峰值從約 260 MB 降到約 40 MB。
- 介面只讀取目前看得見的頁面和浮窗需要的資料，主視窗最小化時基本不再向後端請求。

### 浮窗與介面

- **浮窗不透明度分成兩項**：「背景」和「內容」可以分別調整，背景可以調到完全透明而文字仍清晰。
- 浮窗邊框改為更淡的玻璃細邊。
- 按鈕停留放大時不再被邊緣裁切。
- 合奏頁切換暱稱來源時，右側連線方式開關不再被拉長。
- **動效開關以你的選擇為準**：系統關閉了動畫效果（例如使用遠端桌面）時，只要在設定裡選了「開啟」，動效仍然生效。

### 其他修復

- 關閉自動抓包後手動開始的抓包，現在會在不再需要時停止。
- 擴充模組啟動時偶爾被誤判為違規而失敗的問題。
- 設定裡指定的網卡已不存在時，自動改用全部網卡並在狀態裡說明。
- 抓包出現故障時診斷裡會寫明具體類別，並在幾秒內自動重試。

## 已知問題與限制

- 首領血量需要工具看到首領出現的那一刻；之後才開啟工具時顯示「未讀取」，重新進入首領視野後恢復。
- 有的怪物伺服器不單獨下發血量（例如與另一隻首領共用血量），這時顯示同場首領的血量並標註「同場首領」。
- 浮窗上鎖（滑鼠穿透）時看不到圖示的停留名稱，可在「浮窗版面」頁選中元件查看圖示對照。
- 尋色期間蓋在遊戲畫面上的 Moongate 視窗不會出現在截圖、錄影和遠端桌面畫面裡，移開即可恢復。
- 其餘已知問題見 [0.1.3 更新說明](release-notes-0.1.3.zh-TW.md)與 [0.1.0 更新說明](release-notes-0.1.0.zh-TW.md)。
