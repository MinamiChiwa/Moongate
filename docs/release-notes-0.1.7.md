# Moongate 0.1.7 更新说明

[简体中文](release-notes-0.1.7.md) · [繁體中文](release-notes-0.1.7.zh-TW.md) · [使用说明](user-guide.md) · [返回首页](../README.md)

<!-- release-header:start -->
> **测试版**：各项功能可以使用，但仍可能存在问题。问题与建议请提交至 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。

**下载**：Assets 中的 **`Moongate-v0.1.7-Windows-x64.zip`**（约 170 MB），完整解压后运行 `Moongate.exe`。其余文件供应用内更新与校验使用，无需下载。

**升级**：0.1.6 可在设置页“更新”中检查并安装，仅下载有变化的文件。0.1.5 及更早版本请下载正式包，关闭 Moongate 后以新包中的 `Moongate.exe`、`components`、`licenses` 替换原文件夹中的同名项目，保留 `userdata`。
<!-- release-header:end -->

## 战斗统计

- DPS 浮窗与 DPS 检测页的伤害数据、怪物血量条改为实时更新；战斗记录较多时读取速度不再下降。
- 切换统计范围或怪物标签后，数据立即按新的选择更新。
- 修正部分本人伤害未计入的问题：配对到队友技能（如“生命連結”）的伤害计入本人，技能列表中标注“（队友）”。
- 宠物与召唤物的伤害按设置项“计入召唤物”统计，默认计入。
- 战斗中途开始抓包时，角色识别不再误认为队友。

## 浮窗

- 新增浮窗配色设置：底板、文字、状态、条形、效果条目与图标的颜色均可调整，单个元件可另行设置底板与文字颜色。
- 新增两个收藏浮窗：仅显示已收藏的 buff，未生效时以暗色常驻显示，切换地图后继续倒计时，解锁状态下可拖动排序。收藏范围扩展为游戏客户端中的全部 buff。
- 新增觉醒监控浮窗：显示第一季徽章觉醒与职业觉醒，触发时闪烁提示，可选提示音。
- 元件库改为由开关控制显示与关闭，点击元件仅用于选中编辑；新启用的元件默认处于解锁状态。

## 背包

- 奇幻生活全方位会员生效时，银币与魔族貢品的补充上限显示为 150／15。

## 已知问题

- 觉醒冷却时间在服务器未下发时按 90／60 秒推算，并标注“推算”。
- 仅开通单项会员（未开通全方位会员）时不显示补充上限；会员在登录期间到期，需切换一次频道后恢复为 100／10。
- 其他已知问题见 [0.1.3](release-notes-0.1.3.md) 与 [0.1.0](release-notes-0.1.0.md) 更新说明。

反馈问题时，请在“诊断”页导出排查包，连同问题描述提交至 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。赞助渠道：[爱发电](https://afdian.com/a/minamichiwa)、[Patreon](https://patreon.com/chiwaminami)。
