## 這一版能做什麼

Moongate 是《瑪奇 Mobile》台服的 Windows 桌面工具。它讀取本機的遊戲網路資料來辨識角色、傷害、背包和演奏狀態，並在你開啟相應功能時替你操作遊戲視窗。

- **戰鬥統計（DPS檢測）**：自動統計總傷害、DPS、對每個目標的傷害與你的貢獻占比，暴擊、強擊、連擊、追擊比率，元素構成，依技能與依目標的明細；治療量、HPS 與受到治療的有效比例；自身與怪物身上的效果（Buff）層數與剩餘時間，可收藏常看的效果；破防期間的傷害與時間占比。
- **整場與分段**：切換地圖或脫離戰鬥 3 分鐘後，這一場結束並保留為「上一場」，下次造成傷害時開始新的一場；怪物清完後 10 秒內接著打仍算同一個分段，也可以手動拆段。「重設」一鍵清空整場、分段與定時測量。
- **定時測量與紀錄**：設定時長（例如 1 分鐘），從首次傷害開始計時，結束後列出 DPS 與總傷害；可以替結果命名儲存。明細可以在獨立視窗裡檢視，DPS 曲線停留顯示時間與數值。
- **背包與保管箱**：角色登入時自動讀取背包、角色保管箱與公共保管箱的全部類別，同一帳號的多個角色合併成一張表，沒讀到的地方寫「未讀取」。樂譜每張一列並顯示譜名，停留可見作曲與編曲。概況顯示金幣、銀幣與魔族貢品，銀幣和貢品顯示下一次補充的倒數。支援備註、搜尋、匯出 CSV 和獨立視窗。
- **合奏**：伺服器直連（六位房間碼）或區域網路建房，成員分組與順序，統一倒數後由工具同時點下樂譜「使用」或開始鍵，也可以一起做表情動作；總指揮演奏結束時全員到點一起停止，成員也可以只停止自己。「資訊浮窗」在遊戲上方顯示房間碼、倒數與就緒狀態，可以直接點「開始」「就緒」。
- **染色**：三個區域分別設定目標色（精準 HEX 或相似顏色加容差）與替代色，用螢幕滴管取色，儲存選色方案或套用十套內建配色。支援截圖尋色與精準尋色，顯示實測色碼、色差與候選方案，可以重試；保留最近 30 次尋色紀錄。遊戲與 Moongate 可以放在不同螢幕上，螢幕縮放 100%、125%、150% 都能尋色。「目前顏色」浮窗在遊戲上方逐步提示該做什麼。
- **遊戲浮窗**：DPS、技能、比率、效果、定時測量、治療、合奏資訊、目前顏色等元件可以擺在任意螢幕上。「編輯位置」後直接在螢幕上拖曳、改尺寸，也可以用「移到顯示器」換螢幕。每個元件可以單獨上鎖（滑鼠穿透到遊戲）、調整縮放與不透明度；可儲存多套版面，F8 顯示或隱藏，F7 全部上鎖或解鎖。
- **擴充模組**：匯入素材包替換圖示、背景與動效；安裝第三方擴充模組（ZIP）。帶程式的擴充在獨立程序裡執行，可以提供頁面、浮窗元件、設定項和快捷鍵；一般權限安裝時授予，截圖、連網、讀取檔案、操作遊戲等高風險權限預設關閉，由你逐項開啟。儲存庫附有一個擊殺計時器範例。
- **應用程式內更新**：設定頁「更新」裡可以檢查、下載並「安裝並重新啟動」。只從本專案的 GitHub Releases 下載，核對 SHA-256 後整包替換；新版本啟動失敗時自動回到原版本，`userdata` 裡的資料保留。
- **介面**：简体中文與繁體中文，淺色與深色主題；側欄模組可以拖曳排序；各頁的說明收在標題旁的問號裡，停留或點按檢視。讀不到的資料顯示「未讀取」「未知」，不會用 0 代替。
- **診斷**：檢視執行狀態與最近紀錄，一鍵匯出排查包，方便回報問題。

各功能的操作步驟見[使用說明](user-guide.zh-TW.md)。

### 暫不支援

- **遊戲內自動演奏**：樂譜庫可以瀏覽樂譜、整理清單與演奏佇列，但台服目前讀不到遊戲內的樂譜內容，自動選曲、換裝、開始與停止演奏暫不可用，相關按鈕停用並寫明原因。
- **需要遊戲內時間、天氣、附近演奏的浮窗元件**：標註「台服暫不支援」。
- **合奏的 Cloudflare 公網方式**：需要另外設定 cloudflared，包內沒有附帶；伺服器直連與區域網路可以直接使用。
- **從本機壓縮檔更新**：應用程式內更新只從 GitHub Releases 下載；離線時請依下方「手動升級」操作。

## 使用前須知

- **適用範圍**：只支援《瑪奇 Mobile》台服，Windows 10 / 11 64 位元。
- **需要自行安裝 Npcap**：Moongate 用 Npcap 讀取遊戲網路資料，它不隨工具附帶。請從 [Npcap 官方下載頁](https://npcap.com/#download)下載安裝，保持預設選項即可；沒裝時工具會跳出安裝指引，裝好後約一分鐘內自動開始，不需要重新啟動工具。.NET、Python 與文字辨識元件都已包含在包內。
- **帳號風險**：Moongate 是非官方工具，與 NEXON、devCAT 及台服營運方無關。它讀取遊戲網路資料，開啟合奏、染色或擴充的輸入權限時會自動操作遊戲；精準尋色還會唯讀遊戲記憶體，風險更高。這些行為可能不符合遊戲服務條款，是否使用請自行判斷，帳號因此受到的處置由使用者自行承擔。
- **首次執行的 Windows 提示**：程式沒有程式碼簽章，Windows 可能顯示「Windows 已保護您的電腦」，點「其他資訊」，再點「仍要執行」。
- **資料都在程式資料夾裡**：設定、浮窗版面、備註、紀錄和資料庫都儲存在程式資料夾裡的 `userdata`，不寫入 AppData 或登錄檔。整個資料夾可以移動、改名或複製到別的電腦，資料跟著走；解除安裝時關閉 Moongate，直接刪除整個資料夾即可。
- **放置位置**：放在你有寫入權限的一般資料夾，不要放在 `C:\Program Files`、OneDrive 同步資料夾或網路磁碟裡。在壓縮檔檢視器裡直接按兩下無法執行，請先完整解壓縮。
- **結束**：關閉 Moongate 視窗，背景服務隨之結束，不留背景程序。遊戲以系統管理員身分執行時，Moongate 也需要以系統管理員身分執行才能操作遊戲。

## 已知問題與限制

- 遊戲開著、工具無人操作時，背景服務在部分電腦上仍佔用約 0.2 個 CPU 核心，後續版本繼續最佳化。
- 地圖名稱在進圖後才顯示，剛開始抓包時在遊戲裡切換一次地圖即可；頻道顯示用戶端的頻道序號，副本內顯示「副本頻道」。
- 背包資料在角色登入時下發，工具啟動前已在遊戲中的角色需要重新登入一次。
- 治療統計中藥水、自我治療以及對隊友或寵物施放的治療仍在核對，個別數值可能與遊戲內不一致。
- 染色已在螢幕縮放 100%、125%、150% 下核對，其他縮放比例尚未核對。
- 透過遠端桌面操作時，浮窗元件可能無法直接拖到另一個螢幕，請用浮窗版面頁的「移到顯示器」或浮窗上的箭頭按鈕換螢幕。
- 使用 VPN、加速器或多張網路卡時，可能需要在設定頁的抓包部分手動選擇網路卡。

## 升級與回報

- **之後的升級**：在設定頁「更新」裡點「檢查更新」，發現新版本後「下載更新」，再點「安裝並重新啟動」。正在合奏、染色或定時測量時會等這些活動結束再安裝。
- **手動升級**：把新版本解壓縮到一個新資料夾，關閉 Moongate，把舊資料夾裡的 `userdata` 整個移到新資料夾（與新的 `Moongate.exe` 放在一起），再執行新的 `Moongate.exe`。
- **回報問題**：在「診斷」頁匯出排查包，連同問題描述與重現步驟提交到 [GitHub Issues](https://github.com/MinamiChiwa/Moongate/issues)。
- **支持作者**：如果 Moongate 對你有幫助，歡迎在[愛發電](https://afdian.com/a/minamichiwa)或 [Patreon](https://patreon.com/chiwaminami) 贊助作者一杯咖啡。
