## 已知限制

- **遊戲內自動演奏**尚未實作，樂譜庫裡的「遊戲內演奏」入口停用。附近演奏、遊戲內時間與天氣等需要遊戲資料的浮窗元件標註「台服暫不支援」。
- **地圖與頻道**在抓包收到進圖通知後才顯示，剛開始抓包時在遊戲裡切換一次地圖即可。頻道號取用戶端的頻道序號，副本內顯示「副本頻道」。
- **合奏 Cloudflare 公網方式**需要另外設定 cloudflared，預覽包未附帶；伺服器直連與區域網路可直接使用。
- **擴充模組**只支援純資料擴充（圖片、文字與資料檔）；帶程式的擴充會被拒絕安裝。
- **程式內更新**：預覽版沒有設定更新來源，「檢查更新」不會取得新版本。新版本請到 Releases 下載。
- **數位簽章**：預覽包未簽章，Windows SmartScreen 可能提示，選擇「仍要執行」即可。
- **抓包**依賴 Npcap，使用 VPN、加速器或多張網路卡時可能需要在設定裡手動選擇網路卡。
