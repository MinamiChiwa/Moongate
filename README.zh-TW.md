**Moongate 0.1.5（測試版）**是為《瑪奇 Mobile》台服打造的 Windows 桌面工具，把戰鬥統計、背包與保管箱、多人合奏、染色和遊戲浮窗整合在同一個程式裡。它讀取本機的遊戲網路資料來辨識角色、傷害、背包與演奏狀態，並在你開啟相應功能時代替你對遊戲視窗送出按鍵或點擊（合奏開奏、染色尋色）。0.1.0 是第一個公開版本，目前仍屬於測試版：各項功能已經可以使用，但可能還有問題，歡迎到 [Issues](https://github.com/MinamiChiwa/Moongate/issues) 回報。遊戲內自動演奏樂譜暫不支援。完整清單與已知問題見[更新說明](docs/release-notes-0.1.5.zh-TW.md)。

> **使用風險**
>
> Moongate 是非官方愛好者工具，與 NEXON、devCAT 及《瑪奇 Mobile》台服營運方無關。它讀取遊戲網路資料，並能對遊戲視窗送出輸入；這些行為可能不符合遊戲服務條款。第三方擴充在你授予「向遊戲傳送輸入」後也能以前景或背景方式（不把遊戲視窗帶到前景、不移動滑鼠）自動操作遊戲，背景輸入同樣屬於自動操作遊戲。是否使用由你自行判斷，帳號因此受到的任何處置由使用者自行承擔。

## 1. 下載與安裝

1. 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的最新版本下方 Assets 裡下載排在最上面的 **`Moongate-v0.1.5-Windows-x64.zip`**（約 170 MB）。同一發行裡的 `.sha256` 是校驗值，一般使用者不用下載。
2. 把壓縮檔**完整解壓縮**到一個你有寫入權限的資料夾，例如 `D:\Moongate`。不要放在 `C:\Program Files`、OneDrive 同步資料夾或網路磁碟裡。
3. 按兩下資料夾裡的 **`Moongate.exe`**。第一次啟動會自動完成初始化。在壓縮檔檢視器裡直接按兩下無法執行，工具會提示先完整解壓縮。

| 項目 | 說明 |
|---|---|
| 系統 | Windows 10 / 11 64 位元 |
| 執行環境 | 包內附帶，不需另外安裝 .NET 或 Python |
| 抓包元件 Npcap | **需要自行安裝**，不隨工具發行。未安裝時工具會跳出安裝指引，依指引從 [npcap.com](https://npcap.com/#download) 下載安裝即可，裝好後約一分鐘內自動開始抓包 |
| 文字辨識 Tesseract | 已隨染色元件附帶，不需安裝 |
| 程式簽章 | 程式沒有程式碼簽章，Windows 可能提示「Windows 已保護您的電腦」，點「其他資訊 → 仍要執行」 |

**資料都在工具資料夾裡。** 解壓縮出的 `Moongate` 資料夾根目錄只有 `Moongate.exe`、`components`（程式本體）和 `licenses`（授權與元件清單）。第一次執行後會出現 `userdata` 資料夾，設定、浮窗版面、背包備註、記錄檔和資料庫都在裡面；工具不會在 `AppData`、文件或登錄檔裡另存資料。整個 `Moongate` 資料夾可以移動、改名或複製到其他位置和其他電腦，資料隨 `userdata` 一起走，直接執行 `Moongate.exe` 即可；複製出來的資料夾使用自己的那份資料，與原資料夾互不影響。換了 Windows 使用者後如果提示資料屬於其他使用者，請用原本的使用者執行，或由系統管理員取得該資料夾的擁有權。

**解除安裝**：關閉 Moongate 後直接刪除整個資料夾。

**升級**：在設定頁「更新」裡檢查、下載並「安裝並重新啟動」：工具只從本專案的 GitHub Releases 下載，核對 SHA-256 後替換程式檔案，新版本啟動失敗時自動回到原版本，`userdata` 裡的資料保留。也可以手動升級：把新版本解壓縮到新資料夾，關閉 Moongate 後把舊資料夾裡的 `userdata` 移過去，再執行新的 `Moongate.exe`。

## 2. 第一次使用

1. 啟動遊戲並進入角色。
2. 開啟 Moongate，點左上角的遊戲視窗卡片，選擇《瑪奇 Mobile》視窗（也可以在設定裡開啟「自動選擇遊戲視窗」）。
3. 綁定後自動開始抓包，左上角顯示抓包狀態與目前地圖。合奏、DPS 檢測、背包等功能共用這一份抓包。
4. 開啟需要的頁面使用即可。各頁的說明收在標題旁的問號裡，停留或點按檢視。按 **F9** 隨時緊急停止工具送出的所有遊戲輸入。

關閉 Moongate 視窗即完全結束，背景服務隨之結束。

### 3.1 DPS 檢測

開著抓包戰鬥即可自動統計。頁面頂部可以拆段、結束本場、開始定時測量（例如 1 分鐘，從首次傷害開始計時）、儲存紀錄和「重設」（清空整場、分段與定時測量）；「統計範圍」切換整場、目前分段或定時測量；「選擇目標」只看某個目標的傷害與你的貢獻占比。切換地圖或脫離戰鬥 3 分鐘後這一場結束，保留為「上一場」，下次造成傷害時開始新的一場；脫離戰鬥後 10 秒內又打起來仍算同一個分段。治療卡片顯示 HPS、總治療量與受到治療的有效比例。明細可以在獨立視窗裡檢視，DPS 曲線停留顯示時間與數值。自身效果與怪物效果可以收藏，收藏的效果在浮窗上優先顯示。

### 3.2 背包

角色登入時遊戲會下發完整背包資料，Moongate 收到後自動同步，頁面沒有開始或停止按鈕。樞紐表每列一種道具，列出合計、公共保管箱，以及每個角色的角色保管箱與背包；沒讀到的格子顯示「未讀取」，只有確知沒有時才顯示 0。樂譜每張一列並顯示譜名，停留可見作曲與編曲；銀幣與魔族貢品顯示下一次補充的倒數。可以在「備註」欄寫字、搜尋、匯出 CSV，或在獨立視窗中開啟。

### 3.3 合奏

沿用 MabiSync 的合奏流程。連線方式可選伺服器直連（輸入六位房間碼）或區域網路；Cloudflare 公網方式需要另外設定 cloudflared，包內未附帶。房主建房後分享邀請，成員加入並就緒；房主開始後統一倒數，時間到由工具替每組的樂譜使用者點擊樂譜「使用」或按下開始鍵，參與者在遊戲裡依順序加入。總指揮演奏結束時全員到點一起停止。

### 3.4 染色

沿用 Color Studio 0.5.0 的尋色流程。為三個區域設定目標色、模式（精準 HEX 或相似顏色加 ΔE 容差）、替代色和優先順序，按「開始」後工具在遊戲染色介面自動尋找顏色，顯示實測讀數、分區判定與候選方案。可以用螢幕滴管從任意位置取色，儲存常用的選色方案，或套用內建的十套配色預設。開始尋色需要綁定遊戲視窗（不能最小化）和解壓版內附的染色元件，條件不滿足時「開始」旁寫明原因；尋色期間遊戲視窗保持在前景。執行列和遊戲浮窗的「目前顏色」元件逐步顯示目前階段、需要你做的操作、剩餘時間與遊戲畫面上讀到的色碼，沒有完成時寫明原因與下一步；遊戲與 Moongate 可以放在縮放不同的兩個螢幕上。

### 3.5 浮窗與擴充

在「浮窗版面」頁挑選元件、調整縮放、外觀與不透明度；按「編輯位置」後元件直接顯示在各螢幕上，拖曳擺放、拖右下角改尺寸，也可以用「移到顯示器」換螢幕。浮窗置頂且不搶遊戲焦點。在「模組與擴充」頁可以匯入素材包或安裝擴充模組（ZIP），安裝前會顯示檢查結果與申請的權限供你確認；截圖、連網、讀取檔案、操作遊戲等高風險權限預設關閉，由你逐項開啟。

## 4. 常見問題

- **左上角寫「未抓包：未安裝 Npcap」**：依跳出的指引安裝 Npcap，裝好後不需重新啟動工具。
- **用了 VPN 或加速器後抓不到資料**：確認安裝 Npcap 時勾選了迴環支援；仍不行時到設定頁的抓包部分偵測或指定網路卡。
- **按兩下後沒有出現視窗，或提示背景服務啟動失敗**：在工具資料夾開啟終端機執行 `components\core\launch-backend.cmd -Wait`，視窗會顯示背景服務的啟動輸出與失敗原因，回報問題時一併附上。
- **底部顯示「未連接後端」**：看底部狀態寫的原因。寫著「本機連接埠 19998 已被佔用」時，是另一個資料夾裡的 Moongate 仍在執行（例如解壓縮了兩份），關閉那一份的 Moongate 視窗，或在工作管理員「詳細資料」裡結束命令列含 MabiTool.Host 的 dotnet.exe，再重新開啟。19998 被其他軟體佔用或被系統保留時會自動改用空閒連接埠，不需要處理。
- **怎樣完全結束**：關閉 Moongate 視窗即可，背景服務隨之結束，不留背景程序；進行中的合奏、染色與定時測量會停止並釋放遊戲操作。
- **工具無法對遊戲送出輸入**：如果遊戲以系統管理員身分執行，Moongate 也需要以系統管理員身分執行。
- **回報問題**：在「診斷」頁匯出排查包，連同問題描述一起提交到 [Issues](https://github.com/MinamiChiwa/Moongate/issues)。

更多問題見[使用說明的常見問題](docs/user-guide.zh-TW.md#7-常見問題)。

## 5. 開發者

Moongate 由 .NET 10 本機後端（ASP.NET Core、SQLite）和 Avalonia 12 桌面前端組成，抓包與染色引擎在獨立 Worker 行程中執行。從原始碼建置：

```powershell
pwsh -NoProfile -File .\scripts\build\backend.ps1 -Action Build -Configuration Debug
dotnet .\artifacts\build\bin\MabiTool.Host\debug\MabiTool.Host.dll --initialize-data --portable-root "$PWD\data\dev"
```

儲存庫結構、架構、測試約定與打包發布見[開發文件](docs/development.md)，擴充與素材包的製作方法見[擴充模組開發](docs/extensions.md)和[素材包製作](docs/asset-packs.md)（皆為簡體中文）。
