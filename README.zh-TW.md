**Moongate 0.1.0 預覽版**是為《瑪奇 Mobile》台服打造的 Windows 桌面工具，把戰鬥統計、背包與保管箱、多人合奏、染色和遊戲浮窗整合在同一個程式裡。它讀取本機的遊戲網路資料來辨識角色、傷害、背包與演奏狀態，並在你開啟相應功能時代替你對遊戲視窗送出按鍵或點擊（合奏開奏、染色尋色）。本版本是第一個公開預覽包：DPS 檢測已在台服實際遊戲中驗證，背包、合奏和染色已實作、仍在台服實際遊戲中持續驗證，遊戲內自動演奏樂譜暫不可用。完整清單見[更新說明](docs/release-notes-0.1.0.zh-TW.md)。

> **使用風險**
>
> Moongate 是非官方愛好者工具，與 NEXON、devCAT 及《瑪奇 Mobile》台服營運方無關。它讀取遊戲網路資料，並能對遊戲視窗送出輸入；這些行為可能不符合遊戲服務條款。是否使用由你自行判斷，帳號因此受到的任何處置由使用者自行承擔。

## 1. 下載與安裝

1. 從 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 下載 **`Moongate-v0.1.0-preview-Windows-x64.zip`**。
2. 把壓縮檔**完整解壓縮**到一個你有寫入權限的資料夾，例如 `D:\Moongate`。不要放在 `C:\Program Files`、OneDrive 同步資料夾或網路磁碟裡。
3. 按兩下資料夾裡的 **`Moongate.exe`**。第一次啟動會自動完成初始化。在壓縮檔檢視器裡直接按兩下無法執行，工具會提示先完整解壓縮。

| 項目 | 說明 |
|---|---|
| 系統 | Windows 10 / 11 64 位元 |
| 執行環境 | 包內附帶，不需另外安裝 .NET 或 Python |
| 抓包元件 Npcap | **需要自行安裝**，不隨工具發行。未安裝時工具會跳出安裝指引，依指引從 [npcap.com](https://npcap.com/#download) 下載安裝即可，裝好後約一分鐘內自動開始抓包 |
| 文字辨識 Tesseract | 已隨染色元件附帶，不需安裝 |
| 程式簽章 | 預覽包沒有數位簽章，Windows 可能提示「Windows 已保護您的電腦」，點「其他資訊 → 仍要執行」 |

**資料都在工具資料夾裡。** 解壓縮出的 `Moongate` 資料夾根目錄只有 `Moongate.exe`、`components`（程式本體）和 `licenses`（授權與元件清單）。第一次執行後會出現 `userdata` 資料夾，設定、浮窗版面、背包備註、記錄檔和資料庫都在裡面；工具不會在 `AppData`、文件或登錄檔裡另存資料。整個 `Moongate` 資料夾可以移動、改名或複製到其他位置和其他電腦，資料隨 `userdata` 一起走，直接執行 `Moongate.exe` 即可；複製出來的資料夾使用自己的那份資料，與原資料夾互不影響。換了 Windows 使用者後如果提示資料屬於其他使用者，請用原本的使用者執行，或由系統管理員取得該資料夾的擁有權。

**解除安裝**：關閉 Moongate 後直接刪除整個資料夾。

**升級**：預覽版不提供程式內自動更新。新版本發布後從 Releases 下載新的壓縮檔，具體升級方式見對應版本的更新說明。

## 2. 第一次使用

1. 啟動遊戲並進入角色。
2. 開啟 Moongate，點左上角的遊戲視窗卡片，選擇《瑪奇 Mobile》視窗（也可以在設定裡開啟「自動選擇遊戲視窗」）。
3. 綁定後自動開始抓包，左上角顯示抓包狀態與目前地圖。合奏、DPS 檢測、背包等功能共用這一份抓包。
4. 開啟需要的頁面使用即可。按 **F9** 隨時緊急停止工具送出的所有遊戲輸入。

各功能的操作步驟見[使用說明](docs/user-guide.zh-TW.md)。

### 3.1 DPS 檢測

開著抓包戰鬥即可自動統計。頁面頂部可以拆段、結束本場、開始定時測量（例如 1 分鐘，從首次傷害開始計時）和儲存紀錄；「統計範圍」切換整場、目前分段或定時測量；「選擇目標」只看某個目標的傷害與你的貢獻占比。自身效果與怪物效果可以收藏，收藏的效果在浮窗上優先顯示。

### 3.2 背包

角色登入時遊戲會下發完整背包資料，Moongate 收到後自動同步，頁面沒有開始或停止按鈕。樞紐表每列一種道具，列出合計、公共保管箱，以及每個角色的角色保管箱與背包；沒讀到的格子顯示「未讀取」，只有確知沒有時才顯示 0。可以在「備註」欄寫字、搜尋、匯出 CSV，或在獨立視窗中開啟。

### 3.3 合奏

沿用 MabiSync 的合奏流程。連線方式可選伺服器直連（輸入六位房間碼）或區域網路；Cloudflare 公網方式需要另外設定 cloudflared，預覽包未附帶。房主建房後分享邀請，成員加入並就緒；房主開始後統一倒數，時間到由工具替每組的樂譜使用者點擊樂譜「使用」或按下開始鍵，參與者在遊戲裡依順序加入。總指揮演奏結束時可以讓全員一起停止。

### 3.4 染色

沿用 Color Studio 0.5.0 的尋色流程。為三個區域設定目標色、模式（精準 HEX 或相似顏色加 ΔE 容差）、替代色和優先順序，按「開始」後工具在遊戲染色介面自動尋找顏色，顯示實測讀數、分區判定與候選方案。可以用螢幕滴管從任意位置取色，儲存常用的選色方案，或套用內建的十套配色預設。

### 3.5 浮窗與擴充

在「浮窗版面」頁挑選元件、調整位置大小與外觀，浮窗鋪滿所有顯示器、置頂且不搶遊戲焦點。在「模組與擴充」頁可以匯入素材包或安裝擴充模組（ZIP），安裝前會顯示檢查結果供你確認。

## 4. 常見問題

- **左上角寫「未抓包：未安裝 Npcap」**：依跳出的指引安裝 Npcap，裝好後不需重新啟動工具。
- **用了 VPN 或加速器後抓不到資料**：到設定頁的抓包部分重新偵測或手動選擇網路卡。
- **按兩下後沒有出現視窗，或提示背景服務啟動失敗**：在工具資料夾開啟終端機執行 `components\core\launch-backend.cmd -Wait`，視窗會顯示背景服務的啟動輸出與失敗原因，回報問題時一併附上。
- **底部顯示「未連接後端」**：看底部狀態寫的原因。寫著「本機連接埠 19998 已被佔用」時，是另一個資料夾裡的 Moongate 仍在執行（例如解壓縮了兩份），到那一份的設定頁按「結束 Moongate（含背景服務）」，或在工作管理員「詳細資料」裡結束命令列含 MabiTool.Host 的 dotnet.exe，再重新開啟。
- **關閉視窗後背景服務仍在執行**：這是正常的，抓包、定時測量與浮窗不會因關閉視窗中斷。要完全結束，到設定頁「後端」卡片按「結束 Moongate（含背景服務）」。
- **工具無法對遊戲送出輸入**：如果遊戲以系統管理員身分執行，Moongate 也需要以系統管理員身分執行。
- **回報問題**：在「診斷」頁匯出排查包，連同問題描述一起提交到 [Issues](https://github.com/MinamiChiwa/Moongate/issues)。

更多問題見[使用說明的常見問題](docs/user-guide.zh-TW.md#7-常見問題)。

## 5. 開發者

Moongate 由 .NET 10 本機後端（ASP.NET Core、SQLite）和 Avalonia 12 桌面前端組成，抓包與染色引擎在獨立 Worker 行程中執行。從原始碼建置：

```powershell
pwsh -NoProfile -File .\scripts\build\backend.ps1 -Action Build -Configuration Debug
dotnet .\artifacts\build\bin\MabiTool.Host\debug\MabiTool.Host.dll --initialize-data --portable-root "$PWD\data\dev"
```

儲存庫結構、架構、測試約定、打包與擴充開發見[開發文件](docs/development.md)和[擴充模組開發](docs/extensions.md)（簡體中文）。
