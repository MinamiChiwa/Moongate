**Moongate 0.1.0 预览版**是面向《瑪奇 Mobile》台服的 Windows 桌面工具，把战斗统计、背包与保管箱、多人合奏、染色和游戏浮窗放进同一个程序。它读取本机的游戏网络数据来识别角色、伤害、背包和演奏状态，并在你开启相应功能时代替你向游戏窗口发送按键或点击（合奏开奏、染色寻色）。本版本是第一个公开预览包：DPS 检测已在台服实际游戏中验证，背包、合奏和染色已实现、仍在台服实际游戏中继续验证，游戏内自动演奏乐谱暂不可用。完整清单见[更新说明](docs/release-notes-0.1.0.md)。

> **使用风险**
>
> Moongate 是非官方爱好者工具，与 NEXON、devCAT 及《瑪奇 Mobile》台服营运方无关。它读取游戏网络数据，并能对游戏窗口发送输入；这些行为可能不符合游戏服务条款。是否使用由你自行判断，账号因此受到的任何处置由使用者自行承担。

## 1. 下载与安装

1. 从 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 下载 **`Moongate-v0.1.0-preview-Windows-x64.zip`**。
2. 把压缩包**完整解压**到一个你有写入权限的文件夹，例如 `D:\Moongate`。不要放在 `C:\Program Files`、OneDrive 同步目录或网络磁盘里。
3. 双击文件夹里的 **`Moongate.exe`**。第一次启动会自动完成初始化。在压缩包查看器里直接双击无法运行，工具会提示先完整解压。

| 项目 | 说明 |
|---|---|
| 系统 | Windows 10 / 11 64 位 |
| 运行环境 | 包内自带，无需另装 .NET 或 Python |
| 抓包组件 Npcap | **需要自行安装**，不随工具发行。未安装时工具会弹出安装指引，按指引从 [npcap.com](https://npcap.com/#download) 下载安装即可，装好后约一分钟内自动开始抓包 |
| 文字识别 Tesseract | 已随染色组件附带，无需安装 |
| 程序签名 | 预览包没有数字签名，Windows 可能提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行” |

**数据都在工具文件夹里。** 解压出的 `Moongate` 文件夹根下只有 `Moongate.exe`、`components`（程序本体）和 `licenses`（许可与组件清单）。第一次运行后出现 `userdata` 文件夹，设置、浮窗版面、背包备注、日志和数据库都在里面；工具不在 `AppData`、文档或注册表里另存数据。整个 `Moongate` 文件夹可以移动、改名或复制到其他位置和其他电脑，数据随 `userdata` 一起走，直接运行 `Moongate.exe` 即可；复制出来的文件夹使用自己的那份数据，与原文件夹互不影响。换了 Windows 用户后如果提示数据属于其他用户，请用原来的用户运行，或由管理员取得该文件夹的所有权。

**卸载**：关闭 Moongate 后直接删除整个文件夹。

**升级**：预览版不提供应用内自动更新。新版本发布后从 Releases 下载新的压缩包，具体升级方式见对应版本的更新说明。

## 2. 第一次使用

1. 启动游戏并进入角色。
2. 打开 Moongate，点左上角的游戏窗口卡片，选择《瑪奇 Mobile》窗口（也可在设置里打开“自动选择游戏窗口”）。
3. 绑定后抓包自动开始，左上角显示抓包状态与当前地图。合奏、DPS 检测、背包等功能共用这一份抓包。
4. 打开需要的页面使用即可。按 **F9** 随时紧急停止工具发出的所有游戏输入。

各功能的操作步骤见[使用说明](docs/user-guide.md)。

### 3.1 DPS 检测

开着抓包战斗即可自动统计。页面顶部可以拆段、结束本场、开始定时测量（例如 1 分钟，从首次伤害开始计时）和保存记录；“统计范围”切换整场、当前分段或定时测量；“选择目标”只看某个目标的伤害与你的贡献占比。自身效果与怪物效果可以收藏，收藏的效果在浮窗上优先显示。

### 3.2 背包

角色登录时游戏会下发完整背包数据，Moongate 收到后自动同步，页面没有开始或停止按钮。透视表每行一种道具，列出合计、公共保管箱，以及每个角色的角色保管箱与背包；没读到的格子显示“未读取”，只有确知没有时才显示 0。可以在“备注”列写字、搜索、导出 CSV，或在独立窗口中打开。

### 3.3 合奏

沿用 MabiSync 的合奏流程。联机方式可选服务器直连（输入六位房间码）或局域网；Cloudflare 公网方式需要另行配置 cloudflared，预览包未附带。房主建房后分享邀请，成员加入并就绪；房主开始后统一倒计时，到点由工具替每组的乐谱使用者点击乐谱“使用”或按下开始键，参与者在游戏里按顺序加入。总指挥演奏结束时可以让全员一起停止。

### 3.4 染色

沿用 Color Studio 0.5.0 的寻色流程。为三个区域设定目标色、模式（精准 HEX 或相似颜色加 ΔE 容差）、替代色和优先级，按“开始”后工具在游戏染色界面自动寻找颜色，显示实测读数、分区判定与候选方案。可以用屏幕吸管从任意位置取色，保存常用的选色方案，或套用内置的十套配色预设。

### 3.5 浮窗与扩展

在“浮窗版面”页挑选元件、调整位置大小与外观，浮窗铺满所有显示器、置顶且不抢游戏焦点。在“模块与扩展”页可以导入素材包或安装扩展模块（ZIP），安装前会显示检查结果供你确认。

## 4. 常见问题

- **左上角写“未抓包：未安装 Npcap”**：按弹出的指引安装 Npcap，装好后无需重启工具。
- **用了 VPN 或加速器后抓不到数据**：到设置页的抓包部分重新检测或手动选择网卡。
- **双击后没有出现窗口或提示后台启动失败**：在工具文件夹打开终端运行 `components\core\launch-backend.cmd -Wait`，窗口会显示后台的启动输出与失败原因，反馈问题时一并附上。
- **底部显示“未连接后端”**：看底部状态写的原因。写着“本机端口 19998 已被占用”时，是另一个文件夹里的 Moongate 仍在运行（例如解压了两份），到那一份的设置页按“退出 Moongate（含后台服务）”，或在任务管理器“详细信息”里结束命令行含 MabiTool.Host 的 dotnet.exe，再重新打开。
- **关闭窗口后后台仍在运行**：这是正常的，抓包、定时测量与浮窗不会因关窗中断。要完全退出，到设置页“后端”卡片按“退出 Moongate（含后台服务）”。
- **工具无法对游戏发送输入**：如果游戏以管理员身份运行，Moongate 也需要以管理员身份运行。
- **反馈问题**：在“诊断”页导出排查包，连同问题描述一起提交到 [Issues](https://github.com/MinamiChiwa/Moongate/issues)。

更多问题见[使用说明的常见问题](docs/user-guide.md#7-常见问题)。

## 5. 开发者

Moongate 由 .NET 10 本机后端（ASP.NET Core、SQLite）和 Avalonia 12 桌面前端组成，抓包与染色引擎在独立 Worker 进程中运行。从源码构建：

```powershell
pwsh -NoProfile -File .\scripts\build\backend.ps1 -Action Build -Configuration Debug
dotnet .\artifacts\build\bin\MabiTool.Host\debug\MabiTool.Host.dll --initialize-data --portable-root "$PWD\data\dev"
```

仓库结构、架构、测试约定、打包与扩展开发见[开发文档](docs/development.md)和[扩展模块开发](docs/extensions.md)。
