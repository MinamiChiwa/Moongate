# Moongate · 瑪奇 Mobile 台服工具

**Moongate 0.1.2（测试版）**是面向《瑪奇 Mobile》台服的 Windows 桌面工具，把战斗统计、背包与保管箱、多人合奏、染色和游戏浮窗放进同一个程序。它读取本机的游戏网络数据来识别角色、伤害、背包和演奏状态，并在你开启相应功能时代替你向游戏窗口发送按键或点击（合奏开奏、染色寻色）。0.1.0 是第一个公开版本，目前仍属于测试版：各项功能已经可以使用，但可能还有问题，欢迎到 [Issues](https://github.com/MinamiChiwa/Moongate/issues) 反馈。游戏内自动演奏乐谱暂不支持。完整清单与已知问题见[更新说明](docs/release-notes-0.1.2.md)。

> **使用风险**
>
> Moongate 是非官方爱好者工具，与 NEXON、devCAT 及《瑪奇 Mobile》台服营运方无关。它读取游戏网络数据，并能对游戏窗口发送输入；这些行为可能不符合游戏服务条款。第三方扩展在你授予“向游戏发送输入”后也能以前台或后台方式（不前置游戏窗口、不移动鼠标）自动操作游戏，后台输入同样属于自动操作游戏。是否使用由你自行判断，账号因此受到的任何处置由使用者自行承担。

## 1. 下载与安装

1. 在 [GitHub Releases](https://github.com/MinamiChiwa/Moongate/releases) 的最新版本下方 Assets 里下载排在最上面的 **`Moongate-v0.1.2-Windows-x64.zip`**（约 170 MB）。同一发行里的 `.sha256` 是校验值，普通用户不用下载。
2. 把压缩包**完整解压**到一个你有写入权限的文件夹，例如 `D:\Moongate`。不要放在 `C:\Program Files`、OneDrive 同步目录或网络磁盘里。
3. 双击文件夹里的 **`Moongate.exe`**。第一次启动会自动完成初始化。在压缩包查看器里直接双击无法运行，工具会提示先完整解压。

| 项目 | 说明 |
|---|---|
| 系统 | Windows 10 / 11 64 位 |
| 运行环境 | 包内自带，无需另装 .NET 或 Python |
| 抓包组件 Npcap | **需要自行安装**，不随工具发行。未安装时工具会弹出安装指引，按指引从 [npcap.com](https://npcap.com/#download) 下载安装即可，装好后约一分钟内自动开始抓包 |
| 文字识别 Tesseract | 已随染色组件附带，无需安装 |
| 程序签名 | 程序没有代码签名，Windows 可能提示“Windows 已保护你的电脑”，点“更多信息 → 仍要运行” |

**数据都在工具文件夹里。** 解压出的 `Moongate` 文件夹根下只有 `Moongate.exe`、`components`（程序本体）和 `licenses`（许可与组件清单）。第一次运行后出现 `userdata` 文件夹，设置、浮窗版面、背包备注、日志和数据库都在里面；工具不在 `AppData`、文档或注册表里另存数据。整个 `Moongate` 文件夹可以移动、改名或复制到其他位置和其他电脑，数据随 `userdata` 一起走，直接运行 `Moongate.exe` 即可；复制出来的文件夹使用自己的那份数据，与原文件夹互不影响。换了 Windows 用户后如果提示数据属于其他用户，请用原来的用户运行，或由管理员取得该文件夹的所有权。

**卸载**：关闭 Moongate 后直接删除整个文件夹。

**升级**：在设置页“更新”里检查、下载并“安装并重启”：工具只从本项目的 GitHub Releases 下载，核对 SHA-256 后替换程序文件，新版本启动失败时自动回到原版本，`userdata` 里的数据保留。也可以手动升级：把新版本解压到新文件夹，关闭 Moongate 后把旧文件夹里的 `userdata` 移过去，再运行新的 `Moongate.exe`。

## 2. 第一次使用

1. 启动游戏并进入角色。
2. 打开 Moongate，点左上角的游戏窗口卡片，选择《瑪奇 Mobile》窗口（也可在设置里打开“自动选择游戏窗口”）。
3. 绑定后抓包自动开始，左上角显示抓包状态与当前地图。合奏、DPS 检测、背包等功能共用这一份抓包。
4. 打开需要的页面使用即可。各页的说明收在标题旁的问号里，悬停或点按查看。按 **F9** 随时紧急停止工具发出的所有游戏输入。

关闭 Moongate 窗口即完全退出，后台服务随之退出。

| 背包 | 按道具汇总背包、角色保管箱、公共保管箱的全部类别，乐谱显示谱名，金币、银币与魔族貢品（含补充倒计时），搜索、备注、导出 CSV、独立窗口 | Npcap 抓包 | 可用 |

| 乐谱库 | 浏览乐谱、清单、演奏队列与迷你窗 | — | 浏览可用；游戏内自动演奏暂不支持 |

各功能的操作步骤见[使用说明](docs/user-guide.md)。

### 3.1 DPS 检测

开着抓包战斗即可自动统计。页面顶部可以拆段、结束本场、开始定时测量（例如 1 分钟，从首次伤害开始计时）、保存记录和“重设”（清空整场、分段与定时测量）；“统计范围”切换整场、当前分段或定时测量；“选择目标”只看某个目标的伤害与你的贡献占比。切换地图或脱离战斗 3 分钟后这一场结束，保留为“上一场”，下次造成伤害时开始新的一场；脱离战斗后 10 秒内又打起来仍算同一个分段。治疗卡片显示 HPS、总治疗量与受到治疗的有效比例。明细可以在独立窗口里查看，DPS 曲线悬停显示时间与数值。自身效果与怪物效果可以收藏，收藏的效果在浮窗上优先显示。

### 3.2 背包

角色登录时游戏会下发完整背包数据，Moongate 收到后自动同步，页面没有开始或停止按钮。透视表每行一种道具，列出合计、公共保管箱，以及每个角色的角色保管箱与背包；没读到的格子显示“未读取”，只有确知没有时才显示 0。乐谱每张一行并显示谱名，悬停可见作曲与编曲；银币与魔族貢品显示下一次补充的倒计时。可以在“备注”列写字、搜索、导出 CSV，或在独立窗口中打开。

### 3.3 合奏

沿用 MabiSync 的合奏流程。联机方式可选服务器直连（输入六位房间码）或局域网；Cloudflare 公网方式需要另行配置 cloudflared，包内未附带。房主建房后分享邀请，成员加入并就绪；房主开始后统一倒计时，到点由工具替每组的乐谱使用者点击乐谱“使用”或按下开始键，参与者在游戏里按顺序加入。总指挥演奏结束时全员到点一起停止。

### 3.4 染色

沿用 Color Studio 0.5.0 的寻色流程。为三个区域设定目标色、模式（精准 HEX 或相似颜色加 ΔE 容差）、替代色和优先级，按“开始”后工具在游戏染色界面自动寻找颜色，显示实测读数、分区判定与候选方案。可以用屏幕吸管从任意位置取色，保存常用的选色方案，或套用内置的十套配色预设。开始寻色需要绑定游戏窗口（不能最小化）和解压版自带的染色组件，条件不满足时“开始”旁写明原因；寻色期间游戏窗口保持在前台。运行栏和游戏浮窗的“当前颜色”元件逐步显示当前阶段、需要你做的操作、剩余时间与游戏画面上读到的色码，没有完成时写明原因与下一步；游戏与 Moongate 可以在缩放不同的两块显示器上。

### 3.5 浮窗与扩展

在“浮窗版面”页挑选元件、调整缩放、外观与不透明度；按“编辑位置”后元件直接显示在各显示器上，拖动摆放、拖右下角改尺寸，也可以用“移到显示器”换屏。浮窗置顶且不抢游戏焦点。在“模块与扩展”页可以导入素材包或安装扩展模块（ZIP），安装前会显示检查结果与申请的权限供你确认；截图、联网、读取文件、操作游戏等高风险权限默认关闭，由你逐项打开。

## 4. 常见问题

- **左上角写“未抓包：未安装 Npcap”**：按弹出的指引安装 Npcap，装好后无需重启工具。
- **用了 VPN 或加速器后抓不到数据**：到设置页的抓包部分重新检测或手动选择网卡。
- **双击后没有出现窗口或提示后台启动失败**：在工具文件夹打开终端运行 `components\core\launch-backend.cmd -Wait`，窗口会显示后台的启动输出与失败原因，反馈问题时一并附上。
- **底部显示“未连接后端”**：看底部状态写的原因。写着“本机端口 19998 已被占用”时，是另一个文件夹里的 Moongate 仍在运行（例如解压了两份），关闭那一份的 Moongate 窗口，或在任务管理器“详细信息”里结束命令行含 MabiTool.Host 的 dotnet.exe，再重新打开。19998 被其他软件占用或被系统保留时会自动改用空闲端口，不需要处理。
- **怎样完全退出**：关闭 Moongate 窗口即可，后台服务随之退出，不留后台进程；进行中的合奏、染色与定时测量会停止并释放游戏操作。
- **工具无法对游戏发送输入**：如果游戏以管理员身份运行，Moongate 也需要以管理员身份运行。
- **反馈问题**：在“诊断”页导出排查包，连同问题描述一起提交到 [Issues](https://github.com/MinamiChiwa/Moongate/issues)。

更多问题见[使用说明的常见问题](docs/user-guide.md#7-常见问题)。

## 5. 开发者

Moongate 由 .NET 10 本机后端（ASP.NET Core、SQLite）和 Avalonia 12 桌面前端组成，抓包与染色引擎在独立 Worker 进程中运行。从源码构建：

```powershell
pwsh -NoProfile -File .\scripts\build\backend.ps1 -Action Build -Configuration Debug
dotnet .\artifacts\build\bin\MabiTool.Host\debug\MabiTool.Host.dll --initialize-data --portable-root "$PWD\data\dev"
```

仓库结构、架构、测试约定与打包发布见[开发文档](docs/development.md)，扩展与素材包的制作方法见[扩展模块开发](docs/extensions.md)和[素材包制作](docs/asset-packs.md)。
